Chapter 3: Office Tools — Word Processor

Unit 3 of the CBSE curriculum covers three office tools; this chapter is the first — the word processor (Microsoft Word or LibreOffice Writer — the skills transfer directly between the two). We'll go from a blank page to a fully formatted, print-ready document with pictures, tables, and reviewer comments.

Chapter 3 of 6 Unit 3, Part A ~2.5 Hours Exam-style Questions Included

By the end of this chapter, you'll be able to

  • Format text, spacing, headers/footers and page numbers in a document
  • Insert pictures, bullets/numbering, tables, borders and shading
  • Use spell check, track changes, review comments and drawing tools

3.1 Creating, Saving and Formatting a Document

Text styles and formatting controls
Bold (B), Italic (I), Underline (U)   -- emphasise text
Font type (e.g. Calibri, Times New Roman)
Font size (measured in points, e.g. 12pt body text)
Text colour -- change via the font colour tool
Text alignment -- Left / Centre / Right / Justify
Line spacing -- e.g. single, 1.5, double
Paragraph spacing -- extra space before/after a paragraph

Save your work regularly with File → Save (or Ctrl+S), and give the document a clear, descriptive file name the very first time you save it.

3.2 Headers, Footers and Page Numbering

Where these live on the page
HEADER   text repeated at the TOP of every page
         (e.g. a chapter title or your name)

FOOTER   text repeated at the BOTTOM of every page
         (e.g. a date, or the page number)

PAGE NUMBERING  automatically numbers each page; can be inserted
                into the header or footer and updates itself as
                you add/remove pages

3.3 Spell/Grammar Check and Special Characters

Proofing and symbols
Spell & grammar check   wavy red/blue underlines flag likely
                         errors; right-click for suggested fixes

Subscript (e.g. H2O)    text sits slightly BELOW the baseline
Superscript (e.g. x2)   text sits slightly ABOVE the baseline

Inserting symbols        Insert -> Symbol, for characters not on
                          the keyboard (© ® ° α β etc.)
Print preview before printing

Always check Print Preview before sending a document to the printer — it shows exactly how each page will look, catching margin, spacing or page-break mistakes before you waste paper.

3.4 Pictures, Bullets/Numbering, Borders/Shading and Tables

Adding visual structure
INSERTING PICTURES
  Insert -> Picture -> choose a file; resize by dragging a corner
  handle (hold Shift to keep the aspect ratio)

PAGE SETTINGS
  Layout -> Size / Margins / Orientation (Portrait or Landscape)

BULLETS & NUMBERING
  Bulleted lists for unordered items; numbered lists for sequential
  steps -- both available from the Home/Format toolbar

BORDERS & SHADING
  Add a border or background fill colour to a paragraph, table
  cell, or the whole page via Format -> Borders and Shading
Working with tables
Insert -> Table -> choose rows x columns

Insert/delete a row or column  right-click inside the table ->
                                 Insert/Delete

Merge cells   select two or more cells -> right-click -> Merge Cells
              (combines them into one, e.g. for a table title row)

Split a cell  select one cell -> right-click -> Split Cell
              (divides it into multiple cells)

3.5 Auto-format, Track Changes, Review Comments and Drawing Tools

Collaboration and finishing touches
AUTO-FORMAT      automatically applies consistent styling (like
                 turning straight quotes into curly ones, or a
                 typed web address into a clickable link) as you
                 type

TRACK CHANGES    Review -> Track Changes; every edit a reviewer
                 makes is shown as a marked-up insertion/deletion
                 instead of silently changing the text, so the
                 original author can accept or reject each one

REVIEW COMMENTS  Review -> New Comment; attaches a note to a
                 highlighted bit of text without altering the
                 document itself

DRAWING TOOLS    shapes (rectangles, arrows, callouts) and
                 mathematical symbols can be inserted via
                 Insert -> Shapes / Insert -> Equation

6. Exercise (exam-style, based on the CBSE curriculum)

Unit 3 (Part A) Practice Questions

Work through these on paper

  1. Differentiate between a header and a footer.
  2. What is the use of page numbering in a long document?
  3. Differentiate between subscript and superscript, with one example of each.
  4. Why should you check Print Preview before printing a document?
  5. Explain how to merge two table cells, and give one real situation where you'd need to.
  6. What is the purpose of the Track Changes feature? Who benefits from using it?
  7. How is a review comment different from a tracked change?
  8. List the steps to insert a picture into a document and resize it correctly.
  9. What is auto-format? Give one example of what it automatically changes.
  10. Name two tools you could use to add a shape or mathematical symbol into a document.
