Chapter 1: Basics of Information Technology

Based on the official CBSE Computer Applications (165) curriculum, Unit 1 — 20 marks, the single biggest theory unit. Before touching any software, this chapter covers what a computer is actually built from, the different kinds of software that run on it, how computers connect to each other, and the multimedia content a modern device handles.

Chapter 1 of 6 Unit 1 — 20 Marks ~3 Hours Exam-style Questions Included

By the end of this chapter, you'll be able to

  • Name every major component of a computer system and its job
  • Classify any piece of software as system or application software
  • Distinguish PAN/LAN/MAN/WAN, and explain Wi-Fi, Bluetooth and cloud computing

1.1 Computer Systems

A computer is an electronic device that accepts data, processes it according to instructions, and produces a result. A computer system is the computer together with its hardware and software, working as one functional unit.

Characteristics of a computer
SPEED       performs millions of operations per second
ACCURACY    gives precisely correct results (errors come from bad
            input or faulty programs, not the hardware itself)
DILIGENCE   never gets tired; performs the millionth task as
            accurately as the first
VERSATILITY can perform very different kinds of tasks -- calculations,
            typing documents, playing media, browsing the web
STORAGE     can store massive amounts of data for later retrieval
NO IQ       has no judgement of its own -- does exactly, and only,
            what it is instructed to do
The core components of a computer system
CPU (Central Processing Unit)  the "brain" -- carries out instructions,
                                performs calculations and logic operations
MEMORY                          stores data/instructions currently in use
STORAGE DEVICES                 store data/programs permanently
INPUT DEVICES                   let the user feed data IN to the computer
OUTPUT DEVICES                  show the computer's results to the user

1.2 Memory — Primary Memory

RAM vs. ROM
RAM (Random Access Memory)
  VOLATILE -- contents are LOST when power is switched off
  Temporarily holds data/programs the CPU is actively working with
  More RAM = more programs can run smoothly at once

ROM (Read Only Memory)
  NON-VOLATILE -- contents SURVIVE power-off
  Holds permanent, rarely-changed instructions (like the startup
  instructions that load the operating system when you switch on)

1.2 (continued) Secondary Storage Devices

Where data lives permanently
HARD DISK    the computer's main, large-capacity permanent storage,
             fitted inside the computer case
CD-ROM       an optical disc, read-only, ~700 MB capacity
DVD          an optical disc, higher capacity than a CD (4.7 GB+),
             can store video/large amounts of data
PEN DRIVE /  a small, portable, plug-in-and-go USB storage device
FLASH DRIVE
MEMORY STICK a small flash-memory card, commonly used in cameras/
             phones (SD card, microSD card)
Primary vs. Secondary memory — the key distinction

Primary memory (RAM/ROM) is fast but small, and the CPU accesses it directly. Secondary storage (hard disk, pen drive, etc.) is slower but much larger and permanent — data must first be loaded INTO primary memory before the CPU can actually work on it.

1.3 Input and Output Devices

Getting data in and results out
INPUT DEVICES
  KEYBOARD   types text/commands
  MOUSE      points, clicks, selects on screen
  SCANNER    converts a physical document/photo into a digital image
  WEB CAMERA captures live video/images for calls, photos, streaming

OUTPUT DEVICES
  MONITOR    displays visual output on screen
  PRINTER    produces a physical, paper copy of digital output

1.4 Types of Software

System software vs. Application software
SYSTEM SOFTWARE
  Manages the computer's own hardware and resources; the platform
  everything else runs on top of.
  - OPERATING SYSTEM (Windows, Linux, macOS, Android) -- manages
    memory, files, devices; provides the user interface
  - DEVICE DRIVERS -- small programs that let the OS talk to a
    specific piece of hardware (printer, graphics card, etc.)

APPLICATION SOFTWARE
  Programs written for the END USER to accomplish a specific task --
  word processors, spreadsheets, browsers, games, and photo editors.

MOBILE APPLICATIONS
  Application software specifically built to run on smartphones/
  tablets, usually downloaded from an app store (Play Store, App Store).

1.5 Computer Networking

Network types by geographic scale
PAN (Personal Area Network)  smallest -- a few metres, e.g. your
                              phone connected to a Bluetooth earphone
LAN (Local Area Network)     a single room/building/campus, e.g. a
                              school's computer lab network
MAN (Metropolitan Area       spans a city/town, connecting multiple
Network)                     LANs, e.g. a cable TV network
WAN (Wide Area Network)      spans countries/continents -- the
                              Internet is the largest WAN of all
Wired vs. Wireless, and the key wireless technologies
WIRED COMMUNICATION      data travels through a physical cable
                         (Ethernet cable, fibre optic)
WIRELESS COMMUNICATION   data travels through the air, no cable needed

WI-FI       wireless networking technology that connects devices to
            a local network/router, typically within a home/office/
            campus range
BLUETOOTH   short-range (~10m) wireless technology for connecting
            nearby devices directly (earphones, speakers, file sharing)

CLOUD COMPUTING  storing/accessing data and running software over
                 the Internet instead of on your own local device
  PRIVATE CLOUD   infrastructure dedicated to ONE organisation only
  PUBLIC CLOUD    shared infrastructure, offered to the general
                  public/many customers (Google Drive, Dropbox)

1.6 Multimedia

The four core multimedia content types
IMAGES     still visual content (photos, graphics, icons)
AUDIO      sound content (music, voice recordings, sound effects)
VIDEO      moving visual content with a timeline (movies, clips)
ANIMATION  artificially created movement -- drawn/computer-generated
           frames shown in sequence, rather than recorded footage

8. Exercise (exam-style, based on the CBSE curriculum)

Unit 1 Practice Questions

Work through these on paper

  1. List and explain any four characteristics of a computer.
  2. Draw/describe the block diagram relationship between CPU, memory, input and output devices.
  3. Differentiate between RAM and ROM.
  4. Name two examples each of: input devices, output devices, and secondary storage devices.
  5. Differentiate between system software and application software, giving two examples of each.
  6. What is a device driver, and why is it needed?
  7. Arrange PAN, LAN, MAN, WAN in order of increasing geographic range, with one real-world example of each.
  8. Differentiate between Wi-Fi and Bluetooth.
  9. What is cloud computing? Differentiate between private and public cloud with an example.
  10. Differentiate between video and animation as multimedia content types.
