Chapter 6: Practicals & Project Guide

Theory is only half the marks. This final chapter is a practical exam survival guide — exactly how the 50 practical marks are earned, the official lab exercise list, and how to put together a report file and a small project that ties everything in this course together.

Chapter 6 of 6 Practicals — 50 Marks ~1.5 Hours Course Complete

By the end of this chapter, you'll be able to

  • Explain exactly how the 50 practical marks are distributed
  • List the lab exercises you're expected to be able to perform
  • Plan a report file and a small project combining all three office tools

6.1 How the 50 Practical Marks Break Down

Official breakup of practical marks
Lab Test                                              30 marks
  (Word processing, Spreadsheet, Presentation
   -- a task from each, roughly 10 marks each)
Report File + Viva Voce                               10 marks
  (a portfolio of practical work + an oral exam
   on what's in it)
Project                                                10 marks
  (one small piece of work combining multiple tools)
-----------------------------------------------------------
TOTAL PRACTICALS                                       50 marks

Combined with the 50 theory marks from Units 1-3 (Chapters 1-5), this gives the full 100 marks for CBSE Class 9 Computer Applications.

6.2 The Lab Test and Exercise List

What the lab test actually asks you to do
WORD PROCESSOR TASK (e.g.)
  - Create a formatted document: apply fonts/styles, insert a
    table, add a header/footer with page numbers, insert a picture

SPREADSHEET TASK (e.g.)
  - Enter a small dataset, apply at least one formula/function
    (SUM/AVERAGE/IF), and create an appropriate chart

PRESENTATION TASK (e.g.)
  - Build a short slide deck: consistent layout/background, a
    picture, slide numbers, and one animation or transition
Practise the exact skills, not just the theory

Every lab task maps directly to something covered hands-on in Chapters 3-5 — the single best way to prepare is to actually open the software and redo each example from those chapters yourself, not just re-read them.

6.3 The Report File and Viva

What goes into a report file
A REPORT FILE is a printed (or digital) collection of the
practical work you completed through the year -- typically one
sample document from each of the three office tools, showing the
range of features you practised (tables, formulas, charts,
animations, etc.)

VIVA VOCE  an oral exam where the examiner asks you questions
           about YOUR OWN report file and practical work --
           you must be able to explain what every feature in
           your own work does and why you used it

6.4 Planning Your Project

What makes a good small project
- Pick a simple real-world theme (a class timetable, a small
  shop's sales record, an event poster + slide deck)
- Combine AT LEAST TWO of the three office tools where it makes
  sense -- e.g. a spreadsheet of sales data feeding a chart, then
  a presentation summarising the results
- Keep it small and finishable -- a short, clean, well-formatted
  project beats an ambitious, messy one
- Be ready to explain every choice you made in the viva

5. Exercise (exam-style, based on the CBSE curriculum)

Practicals Practice Questions

Work through these on paper

  1. List the three components of the 50 practical marks and their individual weightage.
  2. What is a report file, and what should it contain?
  3. What is a viva voce, and why must you be able to explain your own practical work in detail?
  4. Describe a word-processing task you might be asked to complete in a lab test.
  5. Describe a spreadsheet task you might be asked to complete in a lab test, including one function you'd use.
  6. Suggest a simple project theme that uses both a spreadsheet and a presentation together, and explain how.
  7. Why is it better to practise each software skill hands-on rather than only reading about it?
  8. What should you be ready to explain about your project during the viva?
