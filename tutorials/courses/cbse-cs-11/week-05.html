5.1 Introduction to Python

An ordered set of instructions for a computer is a program; the language used to write it is a programming language. Computers only understand 0s and 1s (machine/low-level language) — high-level languages like Python exist so humans can write source code instead, which a translator (compiler or interpreter) converts to machine code.

Interpreter vs. Compiler
INTERPRETER  processes statements ONE BY ONE -- translates, then
             executes each -- stops the moment an error is hit.
             Python uses an interpreter.
COMPILER     translates the ENTIRE source code at once into object
             code, reporting all errors after scanning the whole program.
5.1.1 — Features of Python
- High level, free and open source
- Interpreted (executed by the Python interpreter/shell)
- Clearly defined syntax, relatively simple structure
- CASE-SENSITIVE (NUMBER and number are different)
- Portable / platform independent
- Rich library of predefined functions
- Uses INDENTATION for blocks and nested blocks (not braces {})
5.1.3 — Two execution modes
INTERACTIVE MODE  type a statement at the >>> prompt, Enter runs
                   it immediately -- can't be saved/rerun later

SCRIPT MODE       write a full program in a .py file, save it,
                   then run it (Run -> Run Module, or F5, in IDLE)

5.2–5.4 Keywords, Identifiers, Variables & Comments

5.2 — Python Keywords (reserved words — exact case matters)
False  class    finally  is       return
None   continue for      lambda   try
True   def      from     nonlocal while
and    del      global   not      with
as     elif     if       or       yield
assert else     import   pass
break  except   in       raise
5.3 — Rules for naming an identifier
- Starts with a letter (upper/lower) or underscore (_)
- Followed by any mix of a-z, A-Z, 0-9, _  (never starts with a digit)
- Any length (but keep it short and meaningful)
- Must NOT be a keyword
- No special symbols: !, @, #, $, % etc.

Good: marks1, avg, area, length, breadth
Bad:  1st_Room (starts with digit), total-Marks (hyphen not allowed)

A variable refers to an object stored in memory, uniquely identified by its name. Python's variable declaration is implicit — a variable is created the moment it's first assigned a value; it must always be assigned before use in an expression.

5.5 — Comments (start with #, run to end of line)
#Variable amount is the total spending on grocery
amount = 3400
5.6 — Everything is an object

Every value in Python — numeric, string, anything — is an object with a unique identity (ID) for its lifetime, like a memory address. id() returns it. Two variables holding the same value initially share the same ID.

5.7 Data Types

5.7.1 — Number (int, float, complex, bool)
int      whole numbers        -12, -3, 0, 125, 2
float    real/decimal numbers -2.04, 4.0, 14.23
complex  complex numbers      3 + 4j, 2 - 2j
bool     subtype of int: True / False
         True = non-zero, non-null, non-empty; False = zero
5.7.2 — Sequence (String, List, Tuple)
STRING  group of characters, in ' ' or " "         str1 = 'Hello Friend'
LIST    ordered, in [ ], CAN be changed             list1 = [5, 3.4, "New Delhi", 45]
TUPLE   ordered, in ( ), CANNOT be changed once made tuple1 = (10, 20, "Apple", 3.4)
5.7.3–5.7.5 — Set, None, Mapping (Dictionary)
SET   unordered, in { }, NO duplicates, can't be changed once made
      set1 = {10, 20, 3.14, "New Delhi"}

NONE  special single-value type signifying "absence of value" --
      NOT the same as False or 0.   myVar = None

DICTIONARY  key:value pairs in { }, access a value via its key in [ ]
            dict1 = {'Fruit':'Apple', 'Price(kg)':120}
            dict1['Price(kg)']   # 120
5.7.6 — Mutable vs. Immutable (a key exam distinction)
IMMUTABLE (can't change after creation): int, float, bool, complex,
                                          STRING, TUPLE
MUTABLE   (CAN change after creation):   LIST, SET, DICTIONARY

Attempting to "change" an immutable variable actually destroys the
old object and creates a NEW one with the same name -- its id()
changes. A mutable variable keeps the SAME id() when modified.
5.7.7 — Deciding which to use
LIST       simple iterable collection, frequently modified
           (e.g. names of students in a class)
TUPLE      data that should NOT change (e.g. names of months)
SET        need uniqueness, no duplicates (e.g. museum artefacts)
DICTIONARY need fast lookup by a custom key (e.g. a phone book)

5.8–5.9 Operators & Expressions

5.8.1 — Arithmetic operators
+   addition (also string concatenation: "Hello"+"India")
-   subtraction
*   multiplication (also string REPEAT: 'India'*2 -> 'IndiaIndia')
/   division            -- always returns a float
%   modulus (remainder) -- 13 % 5 = 3
//  floor division (integer division, drops the decimal) -- 13//4 = 3
**  exponent (power)    -- 3 ** 4 = 81
5.8.2–5.8.6 — Relational, Assignment, Logical, Identity, Membership
RELATIONAL    ==  !=  >  <  >=  <=        (strings compared by ASCII)
ASSIGNMENT    =  +=  -=  *=  /=  %=  //=  **=
LOGICAL       and  or  not   (lowercase only; "not" is unary)
IDENTITY      is       -- True if both refer to the SAME object (same id)
              is not   -- True if they do NOT share the same id
MEMBERSHIP    in       -- True if value found in a sequence
              not in   -- True if value NOT found in a sequence
5.9.1 — Operator precedence, HIGHEST to LOWEST
1.  **                              Exponentiation
2.  ~, +, -  (unary)                Complement, unary plus/minus
3.  *, /, %, //                     Multiply, divide, modulo, floor div
4.  +, -  (binary)                  Addition, subtraction
5.  <=, <, >, >=, ==, !=            Relational / comparison
6.  =, %=, /=, //=, -=, +=, *=, **=  Assignment
7.  is, is not                      Identity
8.  in, not in                      Membership
9.  not
10. and                             Logical (ascending precedence)
11. or
Worked precedence examples
20 + 30 * 40     = 20 + 1200 = 1220      (* before +)
20 - 30 + 40     = (20-30) + 40 = 30     (equal precedence: left to right)
15.0/4 + (8+3.0) = 3.75 + 11.0 = 14.75   (parentheses evaluated first)

An expression is any combination of constants, variables and operators that evaluates to a value — even a lone value or variable counts, but a standalone operator does not.

5.11–5.12 Input, Output & Type Conversion

input() — ALWAYS returns a string
fname = input("Enter your first name: ")   # 'Arnab'  (string)
age = int(input("Enter your age:"))        # explicit conversion to int
print(value [, sep=' ', end='\n'])
print("I" + "love" + "my" + "country")   # Ilovemycountry  (+ adds NO space)
print("I'm", 16, "years old")            # I'm 16 years old (comma adds space)
5.12.1 — Explicit conversion (type casting) — risk of data loss
int(x)   float(x)   str(x)   chr(x)   ord(x)

num1 = 10; num2 = 20
num3 = num1 + num2            # 30, 
num4 = float(num1 + num2)     # 30.0, 

#WITHOUT explicit str():
print("The total is Rs." + totalPrice)
#TypeError: can only concatenate str (not "int") to str
#WITH explicit str():
print("The total in Rs." + str(totalPrice))   # works fine
5.12.2 — Implicit conversion (coercion) — done automatically
num1 = 10       # int
num2 = 20.0     # float
sum1 = num1 + num2   # 30.0, automatically promoted to float
#(type promotion: converts to the WIDER type, never narrower --
# so an int+float sum is never silently truncated to int)

5.13 Debugging

Debugging is identifying and removing bugs/errors. Three categories:

Syntax, Logical, Runtime errors
SYNTAX ERROR    violates Python's grammar rules -- interpreter won't
                even run the program. E.g. (7 + 11 -- missing ")"

LOGICAL ERROR   (a.k.a. semantic error) -- program runs and finishes,
                but gives the WRONG output. E.g. writing 10 + 12/2 to
                find the average of 10 and 12 (gives 16, not 11) --
                correct form is (10 + 12)/2

RUNTIME ERROR   syntactically fine, but the interpreter can't execute
                it mid-run -- program terminates abnormally.
                E.g. ZeroDivisionError from num1/num2 when num2 is 0,
                or ValueError from int("apple")

7. Exercise (from the textbook)

NCERT Exercise, Chapter 5

Work through these on paper, then verify in Python

  1. Which of these identifier names are invalid, and why: Serial_no., 1st_Room, Hundred$, Total Marks, Total_Marks, total-Marks, _Percentage, True?
  2. Write assignment statements: assign 10/20 to length/breadth; assign their average to sum; assign a list of 3 stationery items; assign 3 name-part strings and concatenate them (with spaces) into fullname.
  3. Write logical expressions for: "sum of 20 and −10 is less than 12"; "num3 is not more than 24"; "6.75 is between num1 and num2"; "'middle' is larger than 'first' and smaller than 'last'"; "list Stationery is empty."
  4. Add a pair of parentheses so each evaluates to True: 0 == 1 == 2, 2 + 3 == 4 + 5 == 7, 1 < -1 == 3 > 4.
  5. Trace the output:
    (a)
    num1, num2 = 2, 6
num1, num2 = num2, num1 + 2
print(num1, num2)
  6. Which data type fits each: months in a year, resident of Delhi (y/n), mobile number, pocket money, volume of a sphere, name of student, address of student?
  7. Give the output when num1=4, num2=3, num3=2:
    quick checks
    num1 += num2 + num3
num1 = num1 ** (num2 + num3)
num1 = '5' + '5'
num1 = 24 // 4 // 2
print(10 != 9 and 20 >= 20)
print((0 < 6) or (not(10 == 6) and (10<0)))
  8. Categorise as syntax, logical or runtime error: 25 / 0; num1 = 25; num2 = 0; num1/num2.
  9. Write a program to convert °C to °F (T(°F) = T(°C) × 9/5 + 32) and verify water's boiling/freezing points.
  10. Write a program for Simple Interest: SI = (P×R×T)/100, Amount = Principal + SI, with P, R, T as input.
  11. Write a program to swap two numbers (a) using a third variable, (b) without using a third variable.
  12. The formula E = mc² gives energy from mass (c ≈ 3×10⁸ m/s). Write a program that accepts mass and computes energy.
