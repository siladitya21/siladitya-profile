Chapter 7: Functions

Based on NCERT's Class XI Computer Science textbook. Using a tent-manufacturer's cost calculation as the running example, this chapter covers why functions exist (modularity and reusability), how to define and call user-defined functions, the difference between an argument and a parameter, default parameters, returning values (including multiple values via a tuple), flow of execution, variable scope (local vs. global), and the Python Standard Library — built-in functions and modules like math, random and statistics.

7.1–7.2 Introduction & Functions

Dividing a program into separate, independently-named blocks with specific functionality is called modular programming. A function is a named group of instructions that performs a specific task when invoked, and can be called repeatedly from anywhere without rewriting its code.

7.2.1 — Advantages of using functions
- Readability: better organised, easier to understand (esp. longer code)
- Reduces code length: same logic not duplicated at multiple places --
  also makes debugging easier
- Reusability: a function can be called from another function or
  another program entirely
- Parallel work: different team members can build different functions

7.3 User Defined Functions

Beyond the Standard Library's ready-made functions, programmers write their own — user-defined functions — using def.

Syntax
def <Function name> ([parameter1, parameter2, ....]):   #Function Header
    set of instructions to be executed                   #Function Body
    [return <value>]                                      #(indented)
Rules
- [ ] parameters are OPTIONAL -- a function may take none
- a function may or may not return a value
- the header always ends with a colon (:)
- function names follow the same rules as identifiers, and must be unique
- code outside the function's indentation is NOT part of the function
Program 7-3 — a function with no parameters
def addnum():
    fnum = int(input("Enter first number: "))
    snum = int(input("Enter second number: "))
    sum = fnum + snum
    print("The sum of ",fnum,"and ",snum,"is ",sum)

addnum()   # function CALL -- nothing runs until this line

7.3.2 Arguments and Parameters

An argument is the value passed to a function at call-time; a parameter is the name in the function header that receives it. Both can even share the same identity (id()) — since both refer to the same object in memory.

Program 7-4 — n passed as an argument
def sumSquares(n):          # n is the PARAMETER
    sum = 0
    for i in range(1,n+1):
        sum = sum + i
    print("The sum of first",n,"natural numbers is: ",sum)

num = int(input("Enter the value for n: "))
sumSquares(num)              # num is the ARGUMENT
What immutability means for parameters — Program 7-5

If a function changes the value of an immutable parameter (an int, say), a brand-new object is created with a new id() — the argument's original object and id outside the function are untouched.

(B) Default parameter — used when the caller omits an argument
def mixedFraction(num, deno = 1):    # deno defaults to 1
    remainder = num % deno
    if remainder != 0:
        quotient = int(num/deno)
        print("The mixed fraction=", quotient, "(", remainder, "/", deno, ")")
    else:
        print("The given fraction evaluates to a whole number")

mixedFraction(17, 2)   # deno overridden with 2 -> "8 ( 1 / 2 )"
mixedFraction(9)       # deno uses its default, 1
Default-parameter rule — exam favourite

Default parameters must be the trailing ones — if one parameter has a default, every parameter after it must too. def calcInterest(principal=1000, rate, time=5) is incorrect; def calcInterest(rate, principal=1000, time=5) is correct.

7.3.3 Functions Returning Value

A function with no return is called a void function — it just performs an action. The return statement hands control back to the caller, carrying value(s) (or None). A function may combine parameters and return values in any of four ways: no-argument/no-return, no-argument/with-return, with-argument/no-return, or with-argument/with-return.

Program 7-10 — a function that returns a value
def calcpow(number,power):
    result = 1
    for i in range(1,power+1):
        result = result * number
    return result

answer = calcpow(5,4)   # answer -> 625
Program 7-12 — returning MULTIPLE values via a tuple
def calcAreaPeri(Length,Breadth):
    area = Length * Breadth
    perimeter = 2 * (Length + Breadth)
    return (area,perimeter)          # a tuple of 2 values

area,perimeter = calcAreaPeri(l,b)    # unpacked in the SAME order returned

7.3.4 Flow of Execution

The Python interpreter runs statements top to bottom — but when it hits a function definition, the body is skipped over (not executed) until the function is actually called. Only then does control jump into the function body, run it, then jump back to right after the call.

A function must be DEFINED before it's CALLED
helloPython()                 #Function Call -- comes FIRST here

def helloPython():            #Function definition -- comes AFTER
    print("I love Programming")

#Result: NameError: name 'helloPython' is not defined
#The interpreter hasn't seen the def yet when it reaches the call.

#CORRECT order:
def helloPython():
    print("I love Programming")

helloPython()                 # now this works

7.4 Scope of a Variable

The part of a program where a variable is accessible is its scope — global or local.

Global vs. Local
GLOBAL VARIABLE  defined OUTSIDE any function/block
                 accessible in any function defined after it

LOCAL VARIABLE   defined INSIDE a function/block
                 accessible ONLY inside that function/block
                 exists only while the function is executing
Program 7-14 — accessing a local variable outside its function fails
num = 5
def myFunc1():
    y = num + 5                           # reads the GLOBAL num fine
    print("Accessing num (global):", num)
    print("Accessing y (local):", y)

myFunc1()
print("num outside:", num)   # works -- 5
print("y outside:", y)       # NameError: name 'y' is not defined
The global keyword — updating a global variable FROM inside a function
num = 5
def myfunc1():
    global num     # without this, 'num = 10' below would create a
                   # NEW LOCAL variable instead, hiding the global one
    print("Accessing num =", num)
    num = 10
    print("num reassigned =", num)

myfunc1()
print("Accessing num outside myfunc1", num)   # 10 -- the global WAS changed

7.5 Python Standard Library

Functions come in three flavours: built-in (always available, e.g. print(), int()), module functions (need import first), and user-defined.

7.5.1 — Commonly used built-in functions

abs, divmod, max, min, pow, sum, len
abs(-5.7)              # 5.7
divmod(7, 2)           # (3, 1)  -- (quotient, remainder) as a tuple
max([1,2,3,4])         # 4         max("Sincerity") -> 'y' (by ASCII)
min(23, 4, 56)         # 4
pow(5, 2, 4)           # (5**2) % 4 = 1   -- optional 3rd arg does modulo
sum([2,4,7,3], 3)      # 19   -- optional 2nd arg adds to the total
len("Patience")        # 8         len({1:"A",2:"B"}) -> 2 (counts keys)

7.5.2 — Modules: math, random, statistics

import math
math.ceil(9.7)        # 10          math.floor(9.7)       # 9
math.fabs(-6.7)       # 6.7         math.factorial(5)     # 120
math.fmod(4.9,-4.9)   # 0.0 (x%y, SIGN OF x)
math.gcd(10,2)        # 2           math.pow(3,2)         # 9.0 (always float)
math.sqrt(144)        # 12.0        math.sin(0)           # 0
import random
random.random()          # random float, 0.0 to 1.0 (exclusive of 1.0)
random.randint(3,7)     # random INT, x to y INCLUSIVE
random.randrange(5)     # random int, 0 up to (not including) 5
random.randrange(2,7)   # random int, 2 up to (not including) 7
import statistics
statistics.mean([11,24,32,45,51])    # 32.6
statistics.median([11,24,32,45,51])  # 32
statistics.mode([11,24,11,45,11])    # 11 (most frequent value)
from ... import ... — load only specific functions, saves memory
from math import ceil, sqrt
value = ceil(624.7)
sqrt(value)             # called WITHOUT the "math." prefix now

#Composition: nesting function calls where one depends on another's output
sqrt(ceil(624.7))       # same idea in one line
Module facts worth remembering

A module is just a .py file of function definitions. It's loaded only once no matter how many times it's imported. A """docstring""" at the top of a module/function documents it — read it back later with print(modulename.__doc__).
