Chapter 3: Emerging Trends

Based on NCERT's Class XI Computer Science textbook. A tour of the technologies reshaping computing right now — Artificial Intelligence (and its sub-areas: Machine Learning, NLP, Virtual/Augmented Reality, Robotics), Big Data and its five characteristics, the Internet of Things, Cloud Computing's three service models, Grid Computing, and Blockchain.

Chapter 3 of 11 NCERT pp. 45–60 ~3 Hours Exercise Included

By the end of this chapter, you'll be able to

  • Explain AI, Machine Learning and NLP with concrete real-world examples
  • Name Big Data's five characteristics (the 5 V's) and distinguish IoT from WoT
  • Differentiate IaaS/PaaS/SaaS, and explain how grid computing differs from cloud

3.2 Artificial Intelligence (AI)

AI endeavours to simulate human intelligence in machines — learning, decision-making, problem solving — often with minimum human intervention, using a knowledge base (facts, assumptions, rules an AI system uses to decide).

3.2.1–3.2.4 — AI's four sub-areas in this chapter
MACHINE LEARNING
  Computers learn from data using statistics, WITHOUT being
  explicitly programmed. Algorithms ("models") are trained on
  training data, tested on testing data, then used on new,
  unknown data once accurate enough.

NATURAL LANGUAGE PROCESSING (NLP)
  Interaction between humans and computers via spoken language
  (Hindi, English...). Powers predictive typing, spell-check,
  voice search, text-to-speech/speech-to-text, machine
  translation, automated customer service.

IMMERSIVE EXPERIENCES
  VIRTUAL REALITY (VR): a 3D computer-generated world you can
    explore and interact with (VR headsets) -- gaming, military
    training, medical procedures.
  AUGMENTED REALITY (AR): superimposes computer-generated info
    OVER the real physical world (doesn't create a new world,
    just augments it) -- location-based travel apps, pointing
    your camera at a landmark for info.

ROBOTICS
  A robot = a programmable machine performing tasks automatically,
  with precision. Sensors are a key component. Types: wheeled,
  legged, manipulators, humanoids. Examples: NASA's Mars rover,
  Sophia the humanoid, drones (journalism, delivery, disaster
  management, agriculture, border patrol).
VR vs. AR — the one-line exam answer

VR replaces your whole surroundings with a simulated one. AR keeps your real surroundings and layers digital information on top.

3.3 Big Data

Enormous, complex data sets that traditional DBMS tools can't handle — not just volume, but unstructured content too (posts, chats, photos, tweets, blogs).

3.3.1 — the five characteristics ("the 5 V's")
VOLUME    sheer size -- too large for traditional DBMS tools
VELOCITY  rate of generation/storage -- exponentially faster than before
VARIETY   structured + semi-structured + unstructured, all mixed
VERACITY  trustworthiness -- is the data noisy, biased, inconsistent?
VALUE     does it hold hidden patterns worth the cost of processing it?

Data analytics examines data sets to draw conclusions, aided by specialised software — Python's Pandas library is named explicitly as a tool that simplifies this.

3.4 Internet of Things (IoT)

A network of devices with embedded hardware/software that communicate with each other — bulbs, fans, a microwave, door locks, CCTV — not just laptops and phones.

3.4.1–3.4.3 — WoT, sensors, smart cities
WEB OF THINGS (WoT)
  Rather than one app per device (N devices = N apps), WoT uses
  web services as ONE common interface to connect everything --
  the basis of smart homes/offices/cities.

SENSORS
  A smart sensor takes input from the physical world, processes
  it with built-in computing, and passes data on. E.g. the
  accelerometer + gyroscope that rotate your phone's display.

SMART CITIES
  IoT + sensors managing a city's land, water, traffic, safety,
  infrastructure. E.g. smart bridges that detect a loose bolt/
  crack and alert authorities via SMS; smart buildings that
  detect earthquake tremors and warn neighbours.

3.5 Cloud Computing

Computer-based services (software, hardware, databases, storage) delivered over the Internet, accessible from anywhere, usually billed pay-per-use — like electricity. Three standard service models:

IaaS, PaaS, SaaS
IaaS (Infrastructure as a Service)
  Rents raw infrastructure -- servers, VMs, storage, networking.
  You configure/deploy/run whatever software you want on it.

PaaS (Platform as a Service)
  A ready environment to develop/test/deploy apps -- e.g. a
  pre-configured Apache server with MySQL + Python already
  installed, so you never touch the underlying setup.

SaaS (Software as a Service)
  Ready-to-use application software, usually subscription-based.
  E.g. Google Docs, Microsoft Office 365, Dropbox -- you just use it.

India's government cloud initiative is called "MeghRaj" (GI Cloud).

3.6 Grid Computing

A network of geographically dispersed, heterogeneous computational resources ("nodes") that temporarily join to solve ONE large task together — a "virtual supercomputer." Two types: Data grid (distributed data, multi-user access) and CPU/Processor grid (a big task split into subtasks across nodes for parallel processing). The Globus toolkit is a well-known open-source grid middleware.

Grid vs. IaaS cloud — a direct exam contrast

In IaaS, a provider rents you infrastructure. In grid computing, multiple independent nodes voluntarily join together to solve one shared computational problem — there's no renting involved.

3.7 Blockchains

Traditional transactions use a centralised database (ticket sites, banks) — risking hacks or loss at that single point. Blockchain works on a decentralised, shared database: every computer holds a full copy. A block is a secured chunk of valid transaction data; blocks chain together, forming the blockchain — an "append-only" open ledger updated only once every node in the network authenticates a transaction.

How a blockchain transaction completes (Figure 3.14)
1. Someone requests a transaction
2. Request is broadcast to ALL nodes in the network
3. If verified by all nodes, the block is added to the existing chain
4. The transaction is complete

Because every member holds a copy, no single member can alter the data — that's what makes it secure. Beyond digital currency, applications include healthcare data sharing, land registration records, and transparent voting systems.

7. Exercise (from the textbook)

NCERT Exercise, Chapter 3

Work through these conceptually

  1. List some cloud-based services you're using right now.
  2. What do you understand by the Internet of Things? List some of its potential applications.
  3. Write short notes on: (a) Cloud Computing, (b) Big Data and its characteristics.
  4. Explain, with applications: (a) Artificial Intelligence, (b) Machine Learning.
  5. Differentiate between cloud computing and grid computing with suitable examples.
  6. Justify: "Storage of data is cost-effective and time saving in cloud computing."
  7. What is on-demand service? How is it provided in cloud computing?
  8. Give examples of: (a) a government-provided cloud computing platform, (b) large-scale private cloud providers and their services.
  9. A company wants a provider offering basic services like virtual server provisioning and on-demand storage, combinable into a platform for deploying customised apps. Which model fits: PaaS, SaaS, "Application as a Service", or IaaS?
  10. For a smart school using IoT — e-textbooks, smart boards, online tests, WiFi door sensors, bus-location sensors, attendance wearables — describe how each could work.
  11. Five friends with limited budget/infrastructure want to launch a startup — how can cloud services help them?
  12. Prepare a report on how blockchain could promote accountability/transparency in government scholarship distribution.
  13. How are IoT and WoT related?
  14. Match the columns:
    Column A → Column B
    1. Reminder to take medication           A. Smart Parking
2. SMS alert you forgot to lock the door B. Smart Wearable
3. SMS alert: parking space available    C. Home Automation
4. Turned off LED TV from your watch     D. Smart Health
