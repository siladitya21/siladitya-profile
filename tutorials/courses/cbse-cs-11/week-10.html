Chapter 10: Tuples and Dictionaries

Based on NCERT's Class XI Computer Science textbook. Two more data types round out Python's core toolkit: the tuple — an ordered, immutable sequence ideal for data that shouldn't change — and the dictionary — an unordered, mutable mapping of unique keys to values, ideal for fast lookups. This chapter covers both fully: operations, built-in methods, tuple assignment/unpacking, nested tuples, and a set of complete dictionary-manipulation programs.

Chapter 10 of 11 NCERT pp. 207–228 ~4 Hours Exercise Included

By the end of this chapter, you'll be able to

  • Explain why a single-element tuple needs a trailing comma, and why tuples are immutable
  • Use tuple assignment/unpacking (e.g. to swap two variables without a temp)
  • Build and manipulate dictionaries with keys(), values(), items(), get(), update(), del

10.1 Introduction to Tuples

A tuple is an ordered sequence in round brackets, able to mix data types — we usually choose list for elements of the same type, tuple for a fixed collection of different types.

The single-element tuple trap
tuple5 = (20)     # NOT a tuple! Just an int, 20 -- parentheses here are just grouping
type(tuple5)      # 

tuple5 = (20,)    # the TRAILING COMMA makes it a tuple
type(tuple5)      # 

seq = 1,2,3       # NO parentheses at all -- still a tuple by default!
type(seq)         #
10.1.2 — Tuple is immutable (but a LIST element inside it isn't)
tuple1 = (1,2,3,4,5)
tuple1[4] = 10
# TypeError: 'tuple' object does not support item assignment

tuple2 = (1,2,3,[8,9])     # 4th element is a MUTABLE list
tuple2[3][1] = 10           # this is legal -- we're mutating the LIST, not the tuple
# tuple2 is now (1, 2, 3, [8, 10])
Why prefer tuples when data won't change

Because a tuple is immutable, iterating through it is faster than a list. And storing fixed data as a tuple protects it from being accidentally overwritten later in the program.

10.2 Tuple Operations

Concatenation, Repetition, Membership, Slicing
tuple1 = (1,3,5,7,9)
tuple2 = (2,4,6,8,10)
tuple1 + tuple2          # (1,3,5,7,9,2,4,6,8,10) -- a NEW tuple, originals unchanged

tuple6 = (1,2,3,4,5)
tuple6 = tuple6 + (6,)    # extend by ONE element -- note the trailing comma!
tuple6 = tuple6 + (7,8,9) # extend by MULTIPLE elements

('Hello','World') * 3    # repeats the WHOLE tuple 3 times

tuple1 = ('Red','Green','Blue')
'Green' in tuple1         # True

tuple1 = (10,20,30,40,50,60,70,80)
tuple1[2:7]                # (30,40,50,60,70)
tuple1[0:len(tuple1):2]    # (10,30,50,70) -- step size 2
tuple1[::-1]                # fully reversed tuple

10.3 Tuple Methods and Built-in Functions

tuple(), count(), index(), sorted(), min/max/sum
tuple1 = tuple('aeiou')     # ('a','e','i','o','u') -- from a string
tuple2 = tuple([1,2,3])      # (1, 2, 3)             -- from a list
tuple3 = tuple(range(5))     # (0, 1, 2, 3, 4)        -- from a range

tuple1 = (10,20,30,10,40,10,50)
tuple1.count(10)    # 3
tuple1.index(30)    # 2  (first occurrence)  -- ValueError if absent

tuple1 = ("Rama","Heena","Raj","Mohsin","Aditya")
sorted(tuple1)   # ['Aditya','Heena','Mohsin','Raj','Rama'] -- returns a LIST
                 # tuple1 itself is UNCHANGED (sorted() never modifies in place)

min(tuple1); max(tuple1); sum(tuple1)

10.4–10.6 Tuple Assignment, Nested Tuples & Tuple Handling

10.4 — Tuple assignment (unpacking)
(num1,num2) = (10,20)
# num1 -> 10, num2 -> 20

record = ("Pooja",40,"CS")
(name,rollNo,subject) = record   # name='Pooja', rollNo=40, subject='CS'

(a,b,c,d) = (5,6,8)
# ValueError: not enough values to unpack (expected 4, got 3)
# -- LEFT and RIGHT side variable counts must match EXACTLY
Program 10-2 — swap two numbers, NO temp variable needed
(num1,num2) = (num2,num1)   # the whole swap, in one line
10.5 — Nested tuples (a tuple of student records)
st = ((101,"Aman",98),(102,"Geet",95),(103,"Sahil",87),(104,"Pawan",79))
for i in range(0,len(st)):
    print((i+1),'\t',st[i][0],'\t',st[i][1],'\t',st[i][2])
# two indices: st[i] selects a student's inner tuple, st[i][0/1/2] selects a field
Program 10-3 — a function returning a tuple of TWO values
def circle(r):
    area = 3.14*r*r
    circumference = 2*3.14*r
    return (area,circumference)   # packs both into one tuple

area,circumference = circle(radius)   # unpacked in one line at the call site

10.7 Introduction to Dictionaries

A dictionary is a mapping between a set of keys and a set of values — each key:value pair is an item. Keys must be unique and of an immutable type (number, string, or tuple); values can be anything, and can repeat.

Creating & accessing — items are accessed by KEY, not position
dict1 = {}                   # empty dict, OR dict2 = dict()
dict3 = {'Mohan':95,'Ram':89,'Suhel':92,'Sangeeta':85}

dict3['Ram']          # 89
dict3['Shyam']        # KeyError: 'Shyam'  -- key must exist

10.8–10.9 Mutability & Dictionary Operations

Dictionaries ARE mutable — add, modify, membership
dict1['Meena'] = 78           # ADDS a brand-new key, since 'Meena' didn't exist
dict1['Suhel'] = 93.5         # MODIFIES the existing 'Suhel' entry (overwrite)

'Suhel' in dict1              # True  -- membership checks against the KEYS
'Suhel' not in dict1          # False
10.10 — Traversing a dictionary, two ways
for key in dict1:
    print(key,':',dict1[key])

for key,value in dict1.items():    # unpacks (key,value) tuples directly
    print(key,':',value)

10.11 Dictionary Methods and Built-in Functions

keys(), values(), items(), get(), update(), del, clear()
dict1 = {'Mohan':95,'Ram':89,'Suhel':92,'Sangeeta':85}
dict1.keys()      # dict_keys(['Mohan','Ram','Suhel','Sangeeta'])
dict1.values()    # dict_values([95, 89, 92, 85])
dict1.items()     # dict_items([('Mohan',95), ('Ram',89), ...])

dict1.get('Sangeeta')   # 85
dict1.get('Sohan')      # None  -- get() never raises KeyError, unlike dict1['Sohan']

dict2 = {'Sohan':79,'Geeta':89}
dict1.update(dict2)      # merges dict2's items INTO dict1 (dict2 itself unchanged)

del dict1['Ram']          # removes ONE item by key
del dict1                 # removes the ENTIRE dictionary variable from memory
dict1.clear()              # empties ALL items, but dict1 itself still exists as {}
get() vs. dict1[key] — a classic exam contrast

dict1[key] raises KeyError if the key is missing. dict1.get(key) safely returns None instead — useful when you aren't sure the key exists.

10.12 Manipulating Dictionaries — worked programs

Program 10-7 — count character frequency with a dictionary
st = input("Enter a string: ")
dic = {}
for ch in st:
    if ch in dic:
        dic[ch] += 1
    else:
        dic[ch] = 1
for key in dic:
    print(key,':',dic[key])
# 'HelloWorld' -> H:1 e:1 l:3 o:2 W:1 r:1 d:1
Program 10-8 — number-to-words using a lookup dictionary
def convert(num):
    numberNames = {0:'Zero',1:'One',2:'Two',3:'Three',4:'Four',
                   5:'Five',6:'Six',7:'Seven',8:'Eight',9:'Nine'}
    result = ''
    for ch in num:
        key = int(ch)
        value = numberNames[key]
        result = result + ' ' + value
    return result
# convert("6512") -> "Six Five One Two"
Deciding tuple vs. dictionary vs. list — exam pattern

Fixed, heterogeneous data that shouldn't change → tuple. Fast lookup by a meaningful key (name, roll number, employee ID) → dictionary. A simple collection of similar items, frequently added to or removed from → list.
