Chapter 1: Computer System

Based on NCERT's Class XI Computer Science textbook. Before any programming, the syllabus starts with the machine itself — the CPU and its registers, input/output devices, how computing evolved from the abacus to the smartphone, the memory hierarchy (RAM, ROM, cache, secondary storage), how data actually moves around a system bus, microprocessors vs. microcontrollers, the three types of data, and the software stack that makes hardware usable — ending with the operating system itself.

Chapter 1 of 11 NCERT pp. 1–26 ~3 Hours Exercise Included

By the end of this chapter, you'll be able to

  • Draw and label a computer system's block diagram, and explain each component
  • Distinguish RAM from ROM, and primary from secondary memory
  • Classify any piece of software as system, programming tool, or application software

1.1 Introduction to Computer System

A computer is an electronic device programmed to accept data (input), process it, and generate a result (output). A computer along with additional hardware and software together is called a computer system — it primarily comprises a CPU, memory, input/output devices and storage devices, all working together as one unit.

Block diagram of a computer system
Input Device --> [ CPU: Control Unit (CU) <-> Arithmetic Logic Unit (ALU)
                       <-> Primary Memory ] --> Output Device
                                   |
                        Secondary Storage Devices

1.1.1 Central Processing Unit (CPU)

The "brain of the computer" — carries out actual processing, physically placed on one or more microchips (integrated circuits). The CPU fetches program and data from memory, performs operations per the instructions, and stores results back. While processing, it uses its own local memory called registers (limited in size and number). Two main components: ALU (performs arithmetic and logic operations) and CU (controls sequential instruction execution and guides data flow). CPU is popularly called a microprocessor.

1.1.2 & 1.1.3 Input and Output Devices

Input devices send control signals/data to a computer, converting it into digital form — keyboard, mouse, scanner, touch screen, braille keyboards, voice input. Data entered is temporarily stored in RAM; for permanent storage it goes to secondary memory. Output devices convert digital information into human-understandable form — monitor, projector, speaker, printer (inkjet/laserjet/dot matrix), 3D printer, braille display monitor.

1.2 Evolution of Computer

Timeline of key inventions
500 BC   Abacus -- mechanical device, simple arithmetic only
1642     Pascaline -- Blaise Pascal's mechanical calculator
1834     Analytical Engine -- Charles Babbage's design: input, process,
         store, display -- considered the basis of modern computers
1890     Tabulating Machine -- Herman Hollerith, summarised punched-card
         data; first real step toward programming
1937     Turing Machine -- Alan Turing's general-purpose programmable
         concept: solve any problem by executing a program from punched cards
1945     EDVAC/ENIAC -- John Von Neumann's STORED PROGRAM concept:
         data AND program both held in memory
1947     Transistor -- replaced vacuum tubes (Bell Labs, semiconductors)
1970     Integrated Circuit (IC) -- entire circuit on one silicon chip;
         computers shrank drastically

The Von Neumann architecture (CPU + memory + I/O + communication channels) underlies ENIAC, the first binary programmable computer built on it.

Later milestones
1970s   Large Scale Integration (LSI) -- full CPU on one chip = microprocessor
1980s   Very Large Scale Integration (VLSI) -- ~3 million components/chip
Later   Super Large Scale Integration (SLSI) -- ~10^6 components/chip
1981    IBM's first home-user PC
1984    Apple Macintosh
1990s   GUI-based OSes (replacing command-line UNIX/DOS) + growth of WWW
Later   Laptops, smartphones, tablets, wearables, IoT + AI-powered appliances
Moore's Law

Intel co-founder Gordon Moore (1965) predicted the number of transistors on a chip would double every two years while cost halved — an exam-favourite fact.

1.3 Computer Memory

1.3.1 Units of Memory

Bit → Nibble → Byte → bigger units
Bit     a single binary digit, 0 or 1
Nibble  4 bits   (e.g. 1001)
Byte    8 bits = 2 nibbles (e.g. 01000110)

1 KB = 1024 Bytes       1 PB = 1024 TB
1 MB = 1024 KB          1 EB = 1024 PB
1 GB = 1024 MB          1 ZB = 1024 EB
1 TB = 1024 GB          1 YB = 1024 ZB

1.3.2 Types of Memory

Primary, Cache & Secondary memory
RAM (Random Access Memory)
  VOLATILE -- contents wiped when power is off
  stores data/programs temporarily while the computer works
  faster than secondary storage; usually called "main memory"

ROM (Read Only Memory)
  NON-VOLATILE -- contents survive power-off
  small, fast, permanent storage for rarely-changed content
  e.g. the boot loader that loads the OS into RAM

CACHE MEMORY
  very high-speed memory BETWEEN the CPU and RAM
  stores copies of frequently-accessed RAM locations
  CPU checks cache FIRST; only falls back to RAM on a miss

SECONDARY MEMORY (storage devices)
  non-volatile, larger capacity, slower, cheaper than RAM
  CANNOT be accessed directly by the CPU -- must first be
  brought into main memory
  e.g. HDD, SSD, CD/DVD, memory card, pen drive, tape drive

1.4 Data Transfer between Memory and CPU

Components transfer data using physical wires called a bus. Three types combine into the system bus:

Data bus, Address bus, Control bus
DATA BUS      transfers data between components -- BIDIRECTIONAL
              (CPU both reads from and writes to memory)
ADDRESS BUS   carries the memory address to read/write -- UNIDIRECTIONAL
CONTROL BUS   carries control signals (read/write commands) -- UNIDIRECTIONAL

To write: CPU puts data on the data bus and the target address on the address bus. To read: CPU specifies the address; a dedicated hardware component called the memory controller places the requested data onto the data bus.

1.5 Microprocessors

A CPU implemented on a single microchip is a microprocessor — today the two terms are used interchangeably.

Table 1.2 — Microprocessor generations (condensed)
Gen 1 (1971-73)  LSI,  4/8-bit,  1 KB      -- Intel 8080
Gen 2 (1974-78)  LSI,  8-bit,    1 MB      -- Motorola 6800, Intel 8085
Gen 3 (1979-80)  VLSI, 16-bit,   16 MB     -- Intel 8086
Gen 4 (1981-95)  VLSI, 32-bit,   4 GB      -- Intel 80386
Gen 5 (1995-now) SLSI, 64-bit,   64 GB, Multicore -- Pentium, Celeron, Xeon

1.5.1 Microprocessor Specifications

Word size, memory size, clock speed, cores
WORD SIZE    max bits processed at once (now 16-64 bits)
MEMORY SIZE  RAM scales with word size (e.g. 64-bit -> up to 16 EB)
CLOCK SPEED  pulses/second from the internal clock; now in GHz
CORES        independent computation units -- dual/quad/octa-core CPUs
             run multiple tasks truly in parallel

1.5.2 Microcontrollers

A microcontroller packs a CPU + fixed RAM + ROM + peripherals all on ONE chip (vs. a microprocessor, which has only the CPU). Embedded in devices for one specific job — keyboard, mouse, washing machine, digital camera, remote controller, microwave — reducing both size and cost.

1.6 Data and Information

A computer treats everything — instructions, pictures, songs, documents — as data: raw, unorganised facts that become meaningful information once processed.

1.6.1 — Three types of data
STRUCTURED DATA
  strict, pre-specified tabular (row/column) format -- easy to sort/
  comprehend. E.g. sales transactions, ATM transactions, attendance
  tables.

UNSTRUCTURED DATA
  no pre-defined record format. E.g. audio/video files, graphics,
  text documents, social media posts, satellite images, a report
  card combining text + graphics.

SEMI-STRUCTURED DATA
  no fixed structure, but uses TAGS/markers to separate data elements.
  E.g. email documents, HTML pages, CSV files.
1.6.2–1.6.3 — Data lifecycle
CAPTURING    gathering data digitally (keyboard, barcode reader,
             social media, remote sensors)
STORAGE      saving captured data for later processing (data servers
             for large organisations)
RETRIEVAL    fetching stored data for processing on demand
DELETION     usually just marks the space as "free" -- doesn't
             actually erase the bits, which is why RECOVERY is often
             possible (if not yet overwritten)
Two data security concerns — exam favourite

Unauthorised deletion (mitigated by passwords, access limits, encryption) vs. unauthorised recovery from discarded storage devices (mitigated by properly shredding/wiping data before disposal).

1.7 Software

Hardware is useless without software — the set of instructions and data that make it functional. Three broad categories:

1.7.2–1.7.4 — System software, Programming tools, Application software
SYSTEM SOFTWARE  interacts directly with hardware, provides basic
  functionality. Includes:
    - Operating System (manages everything)
    - System Utilities (disk defrag, antivirus, disk cleaner)
    - Device Drivers (interface between OS and a specific device)

PROGRAMMING TOOLS  for writing/translating code:
  Low-level languages (machine-dependent): machine language, assembly
  High-level languages (machine-independent, e.g. C++/Java/Python)
  Translators: ASSEMBLER (assembly -> machine code), COMPILER
    (whole high-level program -> machine code, THEN runs), INTERPRETER
    (translates and runs ONE line at a time -- always needed at runtime)
  IDE: text editor + build tools + debugger in one (e.g. Python IDLE)

APPLICATION SOFTWARE  built ON TOP of system software, for end users:
  - General purpose (ready-made, broad audience): LibreOffice Calc,
    Photoshop, a web browser
  - Customised (tailor-made for one org/individual): a school
    management system, a custom accounting tool
1.7.5 — Proprietary vs. Freeware vs. FOSS
FOSS (Free and Open Source Software)  source code + software BOTH
  free -- e.g. Python, LibreOffice, Ubuntu, Mozilla Firefox

FREEWARE  software is free to USE, but source code is NOT available
  -- e.g. Skype, Adobe Reader

PROPRIETARY SOFTWARE  must be purchased from the copyright holder
  -- e.g. Microsoft Windows, Tally, Quick Heal

1.8 Operating System

The OS is a resource manager — it manages CPU, RAM, disk, network and I/O devices, controls application software and device drivers, and handles security/user access. Two primary objectives: (1) run application programs, and (2) provide the user interface.

1.8.1 — Five types of user interface
COMMAND-BASED   type exact commands (keyboard); e.g. MS-DOS, UNIX
GRAPHICAL (GUI) icons/menus/windows; mouse + keyboard; Windows, Ubuntu
TOUCH-BASED     touchscreen taps/swipes; Android, iOS
VOICE-BASED     spoken commands; Siri, "OK Google", Cortana
GESTURE-BASED   waving/tilting/eye motion; emerging smartphone/laptop tech
1.8.2 — Four core functions of an OS
PROCESS MANAGEMENT  allocate CPU among running "processes"
                     (Ctrl+Alt+Delete opens the process/task monitor)
MEMORY MANAGEMENT    allocate/free RAM to processes dynamically,
                     without disturbing other running processes
FILE MANAGEMENT      create/update/delete/PROTECT files on secondary
                     storage (stops one user accessing another's files)
DEVICE MANAGEMENT    coordinate I/O devices via their drivers; also
                     restricts device access to authorised users

9. Exercise (from the textbook)

NCERT Exercise, Chapter 1

Work through these on paper

  1. Name the software required to make a computer functional. What are its two primary services?
  2. How does the computer understand a program written in a high-level language? Why is machine-code execution time shorter than source-code "execution"?
  3. What is the need for RAM? How does it differ from ROM? Why is secondary memory needed at all?
  4. How do different components of the computer communicate with each other? Draw the block diagram of a computer system and briefly describe each component.
  5. What is the primary role of a system bus? Why is the data bus bidirectional while the address bus is unidirectional?
  6. Differentiate between proprietary and freeware software, naming two examples of each.
  7. What's the main difference between a microcontroller and a microprocessor? Why do smart home appliances embed a microcontroller rather than a microprocessor?
  8. Name the types of data you deal with while browsing the Internet. Categorise these as structured/semi-structured/unstructured: Newspaper, Cricket Match Score, HTML Page, Patient records in a hospital.
  9. Name the input/output device used to: (a) output audio, (b) enter textual data, (c) make a hard copy of a text file, (d) display data, (e) enter an audio-based command, (f) build 3D models, (g) assist a visually-impaired person entering data.
  10. Identify the category (system/application/programming tool) of: (a) Compiler, (b) Assembler, (c) Ubuntu, (d) Text editor.
