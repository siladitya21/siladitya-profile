Chapter 9: Lists

Based on NCERT's Class XI Computer Science textbook. Lists are Python's mutable, general-purpose sequence — this chapter covers list operations (concatenation, repetition, membership, slicing), traversal, the full table of built-in list methods, nested lists, the three ways to properly copy a list, the surprising behaviour of passing a list as a function argument, and a complete menu-driven list manipulation program.

Chapter 9 of 11 NCERT pp. 189–206 ~4 Hours Exercise Included

By the end of this chapter, you'll be able to

  • Use every core list method correctly: append, insert, remove, pop, sort, reverse
  • Explain why list2 = list1 is an alias, and name three ways to make a true copy
  • Predict whether a function's changes to a list argument will be visible to the caller

9.1 Introduction to List

A list is an ordered, mutable sequence that can mix data types — integers, floats, strings, tuples, even other lists — all in one list. Elements sit in square brackets, comma-separated; indexing starts at 0, exactly like strings.

9.1.1–9.1.2 — Accessing elements & mutability
list1 = [2,4,6,8,10,12]
list1[0]     # 2         list1[-1]  # 12 (first from the right)
list1[15]    # IndexError: list index out of range
n = len(list1); list1[n-1]  # 12 (last element)

#UNLIKE strings, lists CAN be changed after creation:
list1 = ['Red','Green','Blue','Orange']
list1[3] = 'Black'
# list1 -> ['Red', 'Green', 'Blue', 'Black']

9.2 List Operations

9.2.1–9.2.3 — Concatenation, Repetition, Membership
list1 = [1,3,5,7,9]
list2 = [2,4,6,8,10]
list1 + list2        # [1,3,5,7,9,2,4,6,8,10] -- list1, list2 themselves unchanged

list1 = [1,2,3]
str1 = "abc"
list1 + str1         # TypeError: can only concatenate list (not "str") to list

['Hello'] * 4         # ['Hello','Hello','Hello','Hello']

list1 = ['Red','Green','Blue']
'Green' in list1      # True
'Cyan' not in list1   # True
9.2.4 — Slicing (identical rules to strings)
list1 = ['Red','Green','Blue','Cyan','Magenta','Yellow','Black']
list1[2:6]     # ['Blue','Cyan','Magenta','Yellow']
list1[2:20]    # truncates to the end, no error
list1[7:2]     # []   -- first index > second -> empty list
list1[:5]      # from the start up to (not incl.) index 5
list1[0:6:2]   # ['Red','Blue','Magenta']        -- step size 2
list1[::-1]    # whole list, REVERSED

9.3 Traversing a List

for loop (two styles) and while loop
list1 = ['Red','Green','Blue','Yellow','Black']
for item in list1:
    print(item)

for i in range(len(list1)):   # when you need the INDEX too
    print(list1[i])

i = 0
while i < len(list1):
    print(list1[i])
    i += 1

9.4 List Methods and Built-in Functions

Adding elements — append, extend, insert
list1 = [10,20,30,40]
list1.append(50)            # [10,20,30,40,50]
list1.append([50,60])       # adds the WHOLE list as ONE nested element!

list2 = [40,50]
list1.extend(list2)         # appends EACH element of list2 individually

list1.insert(2,25)          # inserts 25 at index 2, shifting the rest right
Finding & removing — count, index, remove, pop
list1 = [10,20,30,10,40,10]
list1.count(10)        # 3
list1.index(20)        # 1  (first occurrence)
list1.index(90)        # ValueError: 90 is not in list

list1 = [10,20,30,40,50,30]
list1.remove(30)        # removes the FIRST 30 only -> [10,20,40,50,30]
list1.remove(90)        # ValueError: list.remove(x): x not in list

list1 = [10,20,30,40,50,60]
list1.pop(3)             # returns AND removes element at index 3 -> 40
list1.pop()              # no arg -> returns/removes the LAST element
Sorting & aggregate — reverse, sort, sorted, min/max/sum
list1 = [34,66,12,89,28,99]
list1.reverse()              # reverses IN PLACE -> [99,28,89,12,66,34]

list1 = ['Tiger','Zebra','Lion','Cat','Elephant','Dog']
list1.sort()                 # sorts IN PLACE, alphabetically
list1.sort(reverse = True)   # sorts IN PLACE, descending

list1 = [23,45,11,67,85,56]
list2 = sorted(list1)        # returns a NEW sorted list -- list1 UNCHANGED

min(list1)   # smallest       max(list1)   # largest       sum(list1)  # total
sort() vs. sorted() — a classic exam distinction

list.sort() is a method that sorts the list in place and returns None. sorted(list) is a built-in function that leaves the original untouched and returns a brand-new sorted list.

9.5 Nested Lists

A list inside another list is a nested list. Access an element two levels deep with two indices, list1[i][j] — the first index selects the inner list, the second selects the element within it.

Example 9.2
list1 = [1,2,'a','c',[6,7,8],4,9]
list1[4]      # [6, 7, 8]   -- the 5th element IS a list
list1[4][1]   # 7            -- its 2nd element

9.6 Copying Lists

The trap: list2 = list1 does NOT make a copy
list1 = [1,2,3]
list2 = list1          # list2 becomes an ALIAS -- same object, not a copy

list1.append(10)
# BOTH list1 AND list2 now show [1, 2, 3, 10] -- they share one object
Three ways to make a REAL, independent copy
# Method 1 -- slicing
list2 = list1[:]

# Method 2 -- the list() built-in
list2 = list(list1)

# Method 3 -- the copy module
import copy
list2 = copy.copy(list1)

# Any of these three: changing list1 afterward does NOT affect list2

9.7 List as Argument to a Function

Two scenarios, and they behave very differently:

(A) Modifying ELEMENTS IN PLACE — changes ARE reflected back
def increment(list2):
    for i in range(0,len(list2)):
        list2[i] += 5     # modifies the SAME object list1 points to
    print(id(list2))       # same id() as outside!

list1 = [10,20,30,40,50]
increment(list1)
print(list1)   # [15, 25, 35, 45, 55] -- the ORIGINAL list1 changed
(B) Assigning a WHOLE NEW list inside — changes are NOT reflected back
def increment(list2):
    print(id(list2))          # same id as list1, initially
    list2 = [15,25,35,45,55]  # this REBINDS list2 to a NEW object
    print(id(list2))          # a DIFFERENT id now

list1 = [10,20,30,40,50]
increment(list1)
print(list1)   # [10, 20, 30, 40, 50] -- UNCHANGED! list1 never touched
The rule in one line

A list argument passes a reference. Mutating it in place (list2[i] = ..., .append(), etc.) changes the caller's list too. Reassigning the parameter name to a whole new list only rebinds the local name — the caller's original is untouched.

9.8 List Manipulation — a complete example

Program 9-3 in the textbook is a full menu-driven program combining everything in this chapter — append, insert, extend, modify, delete by position, delete by value, sort ascending/descending, and display — wrapped in a while True loop with numbered choices 1–10 and a safe pop(i)/remove(element) pattern that checks bounds/membership first to avoid errors.

Program 9-5 — linear search returning position (or None)
def linearSearch(num,list1):
    for i in range(0,len(list1)):
        if list1[i] == num:
            return i          # found -- return its position
    return None                # exhausted the list, not found

result = linearSearch(num,list1)
if result is None:
    print("Number",num,"is not present in the list")
else:
    print("Number",num,"is present at",result + 1, "position")
