Chapter 11: Data Communication

Based on NCERT's Class XII Computer Science textbook. Building on Chapter 10's network devices and topologies, this chapter zooms into how data actually moves: the five components of any communication, how channel capacity is measured, the three communication modes, circuit vs. packet switching, wired/wireless transmission media, mobile telecom generations, and the protocols that make it all reliable.

Chapter 11 of 13 NCERT pp. 203–222 ~3 Hours Exercise Included

By the end of this chapter, you'll be able to

  • Identify sender, receiver, message, medium and protocol in any communication scenario
  • Compute data transfer rate for a given scenario, and classify simplex/half-duplex/full-duplex
  • Compare wired media (twisted pair, coaxial, fibre) and wireless media, and name key protocols

11.1–11.2 Concept & Components of Data Communication

Data communication is the exchange of data between two or more connected devices. Five components are always present:

The five components
SENDER        device that sends data (computer, phone, smartwatch...)
RECEIVER      device that receives data (computer, printer, TV...)
MESSAGE       the data itself -- text, number, image, audio, video
COMMUNICATION MEDIA  the path the message travels (also called "channel")
PROTOCOL      the rules communicating parties must follow

11.3 Measuring Capacity of Communication Media

Bandwidth vs. Data Transfer Rate
BANDWIDTH -- range of frequencies a channel can carry; measured in Hertz (Hz)
             higher bandwidth -> higher data transfer rate
             1 KHz = 1000 Hz        1 MHz = 1,000,000 Hz

DATA TRANSFER RATE (bit rate) -- bits transmitted per second; measured in bps
             1 Kbps = 2^10 bps = 1024 bps
             1 Mbps = 2^20 bps = 1024 Kbps
             1 Gbps = 2^30 bps = 1024 Mbps
             1 Tbps = 2^40 bps = 1024 Gbps
Example 11.1 — worked problem
Q: Upload 10 pages per 20 seconds. 1 page = 1600 characters,
   each character = 8 bits. Required data rate?

   (10 × 1600 × 8) / 20 = 6400 bps = 6.25 Kbps

11.4 Types of Data Communication

Simplex, Half-duplex, Full-duplex
SIMPLEX      -- ONE direction only. E.g. keyboard input, speaker output,
                controlling IoT home appliances remotely.
                Like a one-way street.

HALF-DUPLEX  -- BOTH directions, but NOT at the same time.
                E.g. a walkie-talkie's push-to-talk button.
                Like a narrow one-way bridge shared by both directions.

FULL-DUPLEX  -- BOTH directions SIMULTANEOUSLY.
                E.g. mobile phones, landline telephones.
                Like a two-way road. Achieved with two separate simplex
                lines, or by sharing one channel's capacity both ways.

11.5 Switching Techniques

Dedicated connections (mesh/star) are costly for large networks — switching routes data through intermediate nodes instead, forming a temporary path.

Circuit Switching vs. Packet Switching
CIRCUIT SWITCHING
  A dedicated path is identified BEFORE communication starts.
  Every packet follows that SAME fixed path.
  E.g. a traditional telephone call.

PACKET SWITCHING
  The message is broken into smaller PACKETS, each with a header
  (destination address + info) and a body (the actual message part).
  Different packets of the SAME message can take DIFFERENT routes.
  The channel is occupied only DURING each packet's transmission --
  freed up immediately after, unlike circuit switching.
  Packets are reassembled in order at the destination.

11.6 Transmission Media

Classified as guided (wired) — a physical cable — or unguided (wireless) — electromagnetic waves through air.

11.6.1 Wired media

Twisted Pair, Coaxial, Fibre Optic
TWISTED PAIR
  Two insulated copper wires twisted together (reduces interference).
  UTP (unshielded) and STP (shielded) variants.
  Cheapest; common in telephone lines and LANs.

COAXIAL CABLE
  Copper core -> insulation -> braided outer conductor -> plastic jacket.
  Better shielded, more bandwidth than twisted pair.
  Carries higher-frequency signals over longer distances.

FIBRE OPTIC
  Carries LIGHT, not electricity, through a glass core + cladding.
  Highest bandwidth, lightest weight, immune to electromagnetic noise,
  longest range -- but expensive and UNIDIRECTIONAL (needs 2 cables
  for full duplex). Used in backbone networks.

11.6.2 Wireless media — by frequency

Radio, Micro, Infrared waves
RADIO WAVES     3 KHz - 1 GHz, omni-directional, penetrate walls
                (low frequencies), used in AM/FM radio, TV, cordless phones

MICROWAVES      1 GHz - 300 GHz, UNIDIRECTIONAL, need line-of-sight,
                cannot penetrate walls/hills, used in satellite/radar

INFRARED WAVES  300 GHz - 400 THz, very high frequency, cannot penetrate
                walls, short-range point-to-point: TV remotes, Bluetooth

BLUETOOTH   Short range (~10m), 2.4 GHz band, 1-2 Mbps. Devices form a
            "piconet" in master-slave mode -- 1 master can talk to up to
            7 active slaves at once (255 devices total, 8 active).

WI-FI (802.11)  Wireless LAN standard. Devices connect via an Access
                Point (AP) that bridges to the wired network.

WiMAX       Like Wi-Fi but larger spectrum, higher data rate, covers a
            much bigger area -- used for MAN-scale wireless access.

11.7 Mobile Telecommunication Technologies

1G through 5G
1G (~1982)   Analog signals, VOICE CALLS ONLY
2G (~1991)   DIGITAL voice -- better quality, security (encryption),
             plus SMS and MMS
3G (~2001)   Digital voice + DATA/Internet over the same towers;
             more simultaneous calls, faster data
4G           Much faster than 3G -- interactive multimedia, video,
             wireless broadband
5G (ongoing) Expected Gbps speeds; built for IoT and Machine-to-Machine
             (M2M) communication at massive scale

11.8 Protocol

A protocol is the set of standard rules communicating parties must follow — needed for flow control (matching sender/receiver speeds so data isn't lost), access control (deciding who uses a shared link when, to avoid packet collisions), and addressing.

Key protocols
HTTP   HyperText Transfer Protocol -- request-response (client-server)
       protocol for the Web, developed by Tim Berners-Lee at CERN, 1989

FTP    File Transfer Protocol -- client-server file transfer; handles
       naming conventions, text/data format, directory differences

PPP    Point-to-Point Protocol -- dedicated direct connection between
       two devices (e.g. two routers, or home PC <-> ISP via modem);
       needs duplex mode; guarantees in-order packet delivery

SMTP   Simple Mail Transfer Protocol -- email service protocol; works
       on the message header (like an envelope), queues outgoing mail,
       delivers to the recipient's mailbox

TCP/IP Transmission Control Protocol / Internet Protocol
       IP: assigns and identifies each node's address
       TCP: breaks data into packets, routes them (possibly via
            different paths), guarantees delivery and correct ORDER,
            reassembles them at the destination

8. Exercise (from the textbook)

NCERT Exercise, Chapter 11

Work through these on paper

  1. What is data communication? Name its main components.
  2. Which communication mode allows communication in both directions simultaneously?
  3. Among LAN, MAN and WAN — which has the highest speed, and which covers the largest area?
  4. What are the three categories of wired media? Explain each.
  5. Compare wired and wireless media. Which transmission medium carries signals as light?
  6. List advantages and disadvantages of optical fibre cable. What is the frequency range for radio waves?
  7. 18 Gbps equals how many bits per second? Write short notes on: HTTP, Bandwidth, Bluetooth, DNS, Data transfer rate.
  8. What is a protocol in data communication? Explain with an example.
  9. A composite signal contains frequencies between 500 MHz and 1 GHz. What is the bandwidth of this signal?
