12.1 Threats and Prevention

A computer disconnected from every network is, in theory, free of network-based threats — but that isn't a realistic option in a connected world. Network security is about protecting devices and data from illegitimate access or misuse. A threat is any way someone can exploit a vulnerability or weakness in a network/communication system to cause harm.

12.2 Malware

Malware ("MALicious softWARE") is software built to damage hardware, steal data, or otherwise cause trouble.

The malware family — key distinguishing facts
VIRUS       Code that infects other programs by inserting itself into
            them. Dormant until the infected file is OPENED/EXECUTED
            by a user -- needs human triggering to spread.
            E.g. CryptoLocker, ILOVEYOU, MyDoom, Stuxnet.

WORM        Unlike a virus, needs NO host program -- a standalone
            program that replicates ON ITS OWN across a network,
            no user action needed. E.g. Code Red, Morris Worm.

RANSOMWARE  Blocks access to user data (or threatens to leak it) and
            demands payment. E.g. WannaCry (2017) -- infected ~200,000
            computers in 150 countries, encrypted data, demanded Bitcoin.

TROJAN      Disguises as legitimate software; once installed, acts
            like a virus/worm. Does NOT self-replicate -- spreads via
            user interaction (opening an attachment, running a download).
            Can create "backdoors" for attacker access.

SPYWARE     Secretly gathers information (browsing habits, card/bank
            details, passwords) and sends it to an external party.

ADWARE      Displays unwanted ads (pop-ups, installer screens) to earn
            revenue for its creator -- usually just annoying, but can
            open the door to other malware via unsafe ad links.

KEYLOGGER   Records every keystroke and may transmit it externally,
            exposing passwords and private messages. Can be software
            OR hardware (a thin device placed under the real keyboard).
On-screen vs. online virtual keyboard — exam favourite

An operating system's on-screen keyboard uses a fixed QWERTY layout, which a keylogger can still exploit. An online virtual keyboard randomises the key layout every single time, making it far harder for a keylogger to know which key was actually pressed.

How malware spreads & how to combat it
DISTRIBUTION: Internet downloads, spam email attachments/links,
infected removable storage (pen drives, memory cards), network
propagation (worms spreading computer-to-computer).

SIGNS OF INFECTION: frequent pop-ups, changed browser homepage,
mass emails sent from your account, slow/crashing computer,
unknown startup programs, sudden storage loss, files
appearing/disappearing without your action.

PREVENTION: keep antivirus updated; configure browser security;
check for the lock icon before paying online; avoid pirated
software (use FOSS instead); apply software patches; back up
data regularly; use a firewall; never enter sensitive data on
public computers/networks; don't click unsolicited links or
attachments; scan removable media before use; never share
banking passwords/PINs.

12.3 Antivirus

Antivirus (anti-malware) software now detects, prevents and removes a wide range of malware, not just viruses, using five main techniques:

Detection methods
SIGNATURE-BASED   compares files against a "Virus Definition File (VDF)"
                  database -- must be updated constantly; fails against
                  polymorphic malware that changes its own signature

SANDBOX           runs a new file in an isolated virtual environment and
                  observes its behaviour before giving it real access --
                  safe but slower

DATA MINING       uses machine learning to classify a file as benign or
                  malicious based on learned patterns

HEURISTICS        compares a suspicious program's source code against a
                  database of known-malware patterns; flags close matches

REAL-TIME         runs continuously in the background, watching for
PROTECTION        suspicious behaviour as programs execute in memory --
                  catches malware that stays dormant until later

12.4–12.5 Spam & HTTP vs. HTTPS

Spam is unsolicited bulk messaging — most recognisably email spam, now largely filtered automatically by services like Gmail, with users able to manually mark missed spam.

HTTP vs. HTTPS
HTTP   sends data AS-IS, unencrypted -- fine for public info (news,
       blogs) but vulnerable to interception

HTTPS  encrypts data before sending, decrypts it at the receiver --
       required for banking, passwords, personal information;
       needs an SSL Digital Certificate; look for "https://" and a
       lock icon before entering sensitive data

12.6–12.7 Firewall & Cookies

Firewall — the first barrier
A security system (software, hardware, or both) that monitors and
controls traffic between a trusted network and an untrusted one
(e.g. the Internet), based on predefined rules.

NETWORK FIREWALL     sits between two or more networks
HOST-BASED FIREWALL  sits on one computer, filters its own traffic
Cookies — small files a website stores on your computer
Used for: shopping cart contents, login state, language preference,
search history, auto-fill form data.

SESSION COOKIE         tracks the current visit; ends on timeout
                        (e.g. auto-logout of a banking site)
AUTHENTICATION COOKIE  remembers you're logged in across pages

Risks: "supercookies" can disguise malware; "zombie cookies"
recreate themselves after deletion; third-party cookies can track
you across sites without consent (e.g. ads that follow a recent
search).

12.8 Hackers and Crackers

People with deep technical knowledge of systems, networks and programming, who find and exploit vulnerabilities — their intent is what separates the three types:

White / Black / Grey Hat
WHITE HAT  "Ethical hacker" -- finds and HELPS FIX security flaws;
           often hired by organisations; works against black hats

BLACK HAT  "Cracker" -- exploits flaws UNETHICALLY, breaking the law

GREY HAT   Hacks out of CHALLENGE/CURIOSITY -- no monetary or
           political motive, sits between the two extremes

12.9 Network Security Threats

DoS vs. DDoS
DoS (Denial of Service)
  Floods a resource (website, email server) with illegitimate
  requests so it appears busy/unavailable to real users.
  A crashed server can simply be restarted; a flooding attack is
  harder to fix since some requests mixed in may be genuine.

DDoS (Distributed DoS)
  Same idea, but the flood comes from many COMPROMISED computers
  ("Zombies") across the globe, controlled via "Bot" malware,
  forming a "Bot-Net." Much harder to block than DoS since there's
  no single source to cut off.
Intrusion techniques & Snooping vs. Eavesdropping
ASYMMETRIC ROUTING   sends intrusion packets via multiple paths to
                     dodge network intrusion sensors
BUFFER OVERFLOW      overwrites memory with malicious code that runs
                     when a programming buffer-overflow bug triggers
TRAFFIC FLOODING     overwhelms the intrusion-detection system itself
                     with packets, so the attacker slips in unnoticed

SNOOPING       secretly CAPTURES and STORES network traffic for later
               analysis -- NOT real-time. Also called sniffing. Not
               always malicious -- admins use it for troubleshooting.
EAVESDROPPING  REAL-TIME unauthorised interception of private
               communication (calls, video, messages) as it happens.
               Older term for this on phone lines: wiretapping.

8. Exercise (from the textbook)

NCERT Exercise, Chapter 12

Work through these on paper

  1. Why is a computer considered safe if it's not connected to a network or the Internet?
  2. What is a computer virus? Name some recently well-known computer viruses. How is a worm different from a virus?
  3. How is ransomware used to extract money from users? How did a Trojan get its name?
  4. How does an adware generate revenue for its creator?
  5. Explain two threats that may arise from an installed keylogger. How is a virtual keyboard safer than an on-screen keyboard?
  6. List and briefly explain different modes of malware distribution. List common signs of a malware infection and preventive measures against it.
  7. Write a short note on the different methods of malware identification used by antivirus software.
  8. What are the risks associated with HTTP? How does HTTPS resolve them?
  9. List one advantage and one disadvantage of using cookies.
  10. Write a short note on White, Black and Grey Hat hackers.
  11. Differentiate between a DoS and a DDoS attack. How is snooping different from eavesdropping?
