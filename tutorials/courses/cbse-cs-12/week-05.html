Chapter 5: Sorting

Based on NCERT's Class XII Computer Science textbook. Sorting is arranging a collection into a particular order — ascending, descending, or alphabetical. This chapter walks through three classic O(n²) algorithms — Bubble sort, Selection sort and Insertion sort — with full Python implementations, then introduces time complexity as the way to reason about how an algorithm scales.

  • Implement all three in Python from memory

5.1 Introduction

Sorting is the process of ordering or arranging a collection of elements — numbers ascending/descending, strings alphabetically or by length. A dictionary's words are sorted alphabetically precisely so looking one up doesn't mean scanning every page. Sorting large collections costs time upfront (called overhead), but that cost is worth paying against how much slower searching an unsorted collection would be.

5.2 Bubble Sort

Repeatedly compares adjacent elements and swaps them if out of order. Each full left-to-right scan is called a pass; for n elements, bubble sort makes n−1 passes. After each pass, the largest remaining element has "bubbled up" to its correct position at the end — and is excluded from every later pass.

Algorithm 5.1 — BUBBLESORT(numList, n)
SET i = 0
WHILE i < n:
    SET j = 0
    WHILE j < n-i-1:
        IF numList[j] > numList[j+1]:
            swap(numList[j], numList[j+1])
        SET j = j+1
    SET i = i+1
Program 5-1
def bubble_Sort(list1):
    n = len(list1)
    for i in range(n):              # number of passes
        for j in range(0, n-i-1):   # last i elements already sorted
            if list1[j] > list1[j+1]:
                list1[j], list1[j+1] = list1[j+1], list1[j]

numList = [8, 7, 13, 1, -9, 4]
bubble_Sort(numList)
print("The sorted list is:")
for i in range(len(numList)):
    print(numList[i], end=" ")
# Output: -9 1 4 7 8 13

Tracing [8, 7, 13, 1, -9, 4]: Pass 1 ends with 13 bubbled to the last position; Pass 2 ends with 8 placed correctly; by the end of Pass 4 the list is already [-9, 1, 4, 7, 8, 13] — Pass 5 runs but makes no swaps, which is the textbook's own hint toward an optimisation: stop early once a pass makes zero swaps.

5.3 Selection Sort

Splits the list conceptually into a sorted left part (empty at first) and an unsorted right part (everything, at first). Each of the n−1 passes scans the entire unsorted part to find its smallest element, then swaps it into the leftmost position of the unsorted part — growing the sorted part by one element every pass.

Algorithm 5.2 — SELECTIONSORT(numList, n)
SET i = 0
WHILE i < n:
    SET min = i, flag = 0
    SET j = i+1
    WHILE j < n:
        IF numList[j] < numList[min]:
            min = j
            flag = 1
        SET j = j+1
    IF flag == 1:
        swap(numList[i], numList[min])
    SET i = i+1
Program 5-2
def selection_Sort(list2):
    flag = 0
    n = len(list2)
    for i in range(n):
        min = i
        for j in range(i + 1, len(list2)):
            if list2[j] < list2[min]:
                min = j
                flag = 1
        if flag == 1:
            list2[min], list2[i] = list2[i], list2[min]

numList = [8, 7, 13, 1, -9, 4]
selection_Sort(numList)
# Output: -9 1 4 7 8 13

Key difference from bubble sort: selection sort does at most n−1 swaps total (one per pass) — bubble sort can swap many times within a single pass. Selection sort trades more comparisons for far fewer writes.

5.4 Insertion Sort

Also splits the list into sorted (left) and unsorted (right) parts, but works like sorting playing cards in your hand: take the next unsorted element and walk backward through the sorted part, shifting each larger element one position right, until you find where the new element belongs — then insert it there.

Algorithm 5.3 — INSERTIONSORT(numList, n)
SET i = 1
WHILE i < n:
    temp = numList[i]
    SET j = i-1
    WHILE j >= 0 and numList[j] > temp:
        numList[j+1] = numList[j]
        SET j = j-1
    numList[j+1] = temp      # insert temp at its correct position
    SET i = i+1
Program 5-3
def insertion_Sort(list3):
    n = len(list3)
    for i in range(n):
        temp = list3[i]
        j = i-1
        while j >= 0 and temp < list3[j]:
            list3[j+1] = list3[j]
            j = j-1
        list3[j+1] = temp

numList = [8, 7, 13, 1, -9, 4]
insertion_Sort(numList)
# Output: -9 1 4 7 8 13
Exam point

An already-sorted list is insertion sort's best case — each inner while stops immediately, so very few comparisons happen. A reverse-sorted list is its worst case — maximum shifting every single pass.

5.5 Time Complexity of Algorithms

Time complexity is the amount of time an algorithm takes to process given data — it matters most once data sets grow large, where small-list timing differences between algorithms disappear into noise. Four rules of thumb from the textbook:

Classifying time complexity by loop structure
No loop at all              → constant time,  complexity 1
A single loop (1 to n)      → linear time,     complexity n
A loop nested inside a loop → quadratic time,  complexity n^2
A nested loop + a separate
  single loop in the same
  algorithm                 → complexity is based on the NESTED loop only

All three sorting programs in this chapter — bubble, selection and insertion sort — have one loop nested inside another, so all three are quadratic time, n² algorithms.

6. Exercise (from the textbook)

NCERT Exercise, Chapter 5

Work through these on paper, then verify in Python

  1. For numList = [7, 11, 3, 10, 17, 23, 1, 4, 21, 5], show the partially sorted list after three complete passes of bubble sort.
  2. For List 1: 63 42 21 9, count the swaps required by selection sort vs. bubble sort, and decide which is better by number of comparisons.
  3. Given List 1 2 3 5 7 11 and List 2 11 7 5 3 2, which makes the minimum number of comparisons under insertion sort? Justify with a diagram.
  4. Write a program (using a user-defined function) that accepts a list of numbers and returns its median. (Hint: sort with bubble sort first; for odd count take the centre term, for even count average the two middle terms.)
  5. Write a program that accepts a list of n students' marks and calculates the xth percentile:
    1. Sort the values (selection sort, or any method).
    2. index = x% × n — e.g. 90th percentile of 120 students: 0.90 × 120 = 108.
    3. Round the index to a whole number with math.round().
    4. The value at that index is the xth percentile.
  6. During course admission, student names are inserted keeping the list in ascending order at all times — identify which sorting technique this resembles, and write a user-defined function invoked on every new name that inserts it in the correct sorted position.
