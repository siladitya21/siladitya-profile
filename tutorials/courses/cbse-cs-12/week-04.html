Chapter 4: Queue

Based on NCERT's Class XII Computer Science textbook. Where a stack is Last-In-First-Out, a Queue is First-In-First-Out (FIFO) — like a line of people at a bank counter. This chapter covers ENQUEUE and DEQUEUE, implementing a queue with a Python list, and the double-ended variant, Deque, which allows insertion and deletion at both ends and can itself emulate either a stack or a queue.

  • Implement a deque and use it to check whether a string is a palindrome

4.1 Introduction to Queue

A Queue is an ordered linear list with different ends for adding and removing elements, following First-In-First-Out (FIFO) — also called First-Come-First-Served. New elements are added at the REAR (TAIL); elements are removed from the FRONT (HEAD). Everyday examples: people at a bank counter, vehicles at a toll booth, a train ticket's waiting list.

In computer science

A print spooler queues documents from multiple sources and sends them to the printer FIFO. A multitasking OS queues jobs for the processor. A web server with limited concurrent capacity queues incoming requests.

4.2 Operations on Queue

  • ENQUEUE — insert a new element at the REAR. Beyond capacity → Overflow.
  • DEQUEUE — remove the element at the FRONT. On an empty queue → Underflow.
  • IS EMPTY — checks for zero elements (avoids Underflow before dequeue).
  • PEEK — reads the FRONT element without removing it.
  • IS FULL — checks capacity (avoids Overflow before enqueue).
Figure 4.3 — queue trace (FRONT left, REAR right)
enqueue(z)   F[ Z ]R
enqueue(x)   F[ Z  X ]R
enqueue(c)   F[ Z  X  C ]R
dequeue()    F[ X  C ]R        -- removes Z
enqueue(v)   F[ X  C  V ]R
dequeue()    F[ C  V ]R        -- removes X
dequeue()    F[ V ]R           -- removes C

4.3 Implementation of Queue using Python

As with a stack, a Python list works, but a queue needs opposite ends fixed for insertion vs. deletion — append() for ENQUEUE (always adds at the end = REAR), pop(0) for DEQUEUE (always removes from the start = FRONT).

Queue functions built on a Python list
myQueue = list()

def enqueue(myQueue, element):
    myQueue.append(element)        # always adds at the REAR

def isEmpty(myQueue):
    if len(myQueue) == 0:
        return True
    else:
        return False

def dequeue(myQueue):
    if not (isEmpty(myQueue)):
        return myQueue.pop(0)      # always removes from the FRONT
    else:
        print("Queue is empty")

def size(myQueue):
    return len(myQueue)

def peek(myQueue):
    if isEmpty(myQueue):
        print('Queue is empty')
        return None
    else:
        return myQueue[0]
No Is Full needed

Just like the stack chapter, Python's dynamic lists have no fixed size, so there's never a true queue-full condition to check for — unlike in languages with fixed-size arrays.

Program 4-1 — bank counter queue
myQueue = list()
element = input("enter person's code to enter in queue: ")
enqueue(myQueue, element)                 # P1
element = input("enter person's code for insertion in queue: ")
enqueue(myQueue, element)                 # P2
print("person removed from queue is:", dequeue(myQueue))   # P1
print("Number of people in the queue is:", size(myQueue))  # 1

# three more people join...
for _ in range(3):
    element = input("enter person's code to enter in queue: ")
    enqueue(myQueue, element)             # P3, P4, P5

print("Now we are going to remove remaining people from the queue")
while not isEmpty(myQueue):
    print("person removed from queue is", dequeue(myQueue))

4.4 Introduction to Deque

A Deque (pronounced "deck", short for Double-Ended Queue) allows insertion and deletion from either end — front/head or rear/tail. It has no restriction on which side is used for which operation, so it can emulate a pure stack, a pure queue, or something in between.

4.4.2 — four core operations
INSERTFRONT    insert a new element at the front
INSERTREAR     insert a new element at the rear (same as enqueue)
DELETIONFRONT  remove an element from the front (same as dequeue)
DELETIONREAR   remove an element from the rear
Classic exam application — palindrome check

Insert every character of "madam" at the REAR as a normal queue. Then repeatedly remove one character from the FRONT and one from the REAR and compare them; if they always match until the deque is empty (or one character remains), the string is a palindrome.

4.5 Implementation of Deque Using Python

insert(0, element) puts something at the front; append() and plain pop() (no index) handle the rear, same as a stack's PUSH/POP.

Program 4-2 — deque functions
def insertFront(myDeque, element):
    myDeque.insert(0, element)

def insertRear(myDeque, element):
    myDeque.append(element)

def isEmpty(myDeque):
    if len(myDeque) == 0:
        return True
    else:
        return False

def getFront(myDeque):
    if not (isEmpty(myDeque)):
        return myDeque[0]
    else:
        print("Queue underflow")

def getRear(myDeque):
    if not (isEmpty(myDeque)):
        return myDeque[len(myDeque)-1]
    else:
        print("Queue underflow")

def deletionFront(myDeque):
    if isEmpty(myDeque):
        print("Queue underflow")
    else:
        return myDeque.pop(0)

def deletionRear(myDeque):
    if not isEmpty(myDeque):
        return myDeque.pop()
    else:
        print("Queue underflow")

With these six functions, the same deque can act as a FIFO queue (insert rear, delete front) or a LIFO stack (insert rear, delete rear) just by choosing which pair of operations to call.
