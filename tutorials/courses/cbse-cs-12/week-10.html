Chapter 10: Computer Networks

Based on NCERT's Class XII Computer Science textbook. From ARPANET's first message in 1969 to the Internet connecting billions of devices today — this chapter covers how networks are classified by scale (PAN/LAN/MAN/WAN), the devices that build them (modem, hub, switch, router, gateway), the topologies that arrange them, how nodes are uniquely identified (MAC/IP addresses), and how the Web and DNS actually work.

  • Compare mesh, ring, bus, star and tree topologies on reliability, cost and failure behaviour
  • Explain MAC vs. IP addressing, and how DNS resolves a domain name to an IP address

10.1–10.2 Introduction & Evolution of Networking

A computer network is an interconnection among two or more computers or computing devices, allowing them to share data and resources. Each device in a network — a server, desktop, laptop, phone, or networking device like a switch — is called a node. Data travels across a network broken into smaller chunks called packets.

Evolution timeline — key milestones
1961  ARPANET conceptualised (US Dept. of Defence research project)
1969  ARPANET functional -- first message: UCLA to Stanford Research Institute
1971  Ray Tomlinson develops network email -- @ comes to mean "at"
1974  The term "Internet" is coined; first commercial ARPANET use (Telenet)
1982  TCP/IP introduced as ARPANET's standard protocol
1983  Domain Name System (DNS) introduced
1986  NSFNET program brings connectivity to more people
1990  Tim Berners-Lee at CERN develops HTML and URL -- birth of the World Wide Web
1997  First Wi-Fi (802.11) standard introduced

10.3 Types of Networks

Networks are categorised by geographical area covered and data transfer rate:

PAN, LAN, MAN, WAN
PAN (Personal Area Network)
  Range: ~10 metres. E.g. phone-to-laptop via USB (wired),
  two phones via Bluetooth (wireless/WPAN).

LAN (Local Area Network)
  Range: up to ~1 km -- a room, floor, building, campus.
  Data rate: 10 Mbps (Ethernet) to 1000 Mbps (Gigabit Ethernet).
  Comparatively secure; only authentic users access shared resources.

MAN (Metropolitan Area Network)
  An extended LAN covering a city/town, up to ~30-40 km.
  Lower data rate than LAN. E.g. cable TV network, cable broadband.
  Often formed by connecting multiple LANs together.

WAN (Wide Area Network)
  Connects LANs/MANs across a country or continents.
  The Internet is the largest WAN -- connects billions of devices.

10.4 Network Devices

The core device list
MODEM (MOdulator DEModulator)
  Converts digital data <-> analog signals for transmission.
  Sender's modem modulates; receiver's modem demodulates.

ETHERNET CARD / NIC (Network Interface Card)
  Circuit board that interfaces a computer with a wired network.
  Every NIC has a unique MAC address burned in at manufacture.

RJ45
  8-pin plastic connector at the end of Ethernet cables.

REPEATER
  Regenerates a weakened signal (signals weaken past ~100m on cable).

HUB
  Connects multiple devices; broadcasts incoming data to ALL ports.
  Limitation: simultaneous data from two devices COLLIDES.

SWITCH
  Like a hub, but reads the destination address and sends data
  ONLY to the intended device. Can forward multiple packets at
  once; drops noisy/corrupted signals and asks for a resend.

ROUTER
  Connects a LAN to the Internet; analyses data, can repackage it
  into different packet sizes for a different network type, and
  decides the routing path. Home Wi-Fi routers often double as
  modem + switch.

GATEWAY
  The "gate" between an organisation's network and the outside
  Internet -- entry/exit point for all traffic, maintains routing
  paths to foreign networks. Usually implemented on a router;
  firewalls are commonly integrated here.

10.5 Networking Topologies

Topology is the arrangement of computers and peripherals in a network. Five common topologies:

Mesh, Ring, Bus, Star, Tree/Hybrid
MESH   -- every device connected to every other device
          + handles heavy traffic, very reliable (one node down
            doesn't break others), most secure (separate cable per link)
          - complex wiring, high cost; needs n(n-1)/2 wires for n nodes

RING   -- each node connected to exactly two neighbours, forming a loop
          data flows in ONE direction only (clockwise or counter-clockwise)

BUS    -- all devices share a single backbone cable
          + cheap, easy to maintain
          - less secure/reliable; a backbone break affects everyone

STAR   -- every device connects to one central hub/switch
          + effective, fast, one device's failure doesn't affect others
          - if the CENTRAL device fails, the WHOLE network goes down

TREE/HYBRID -- hierarchical; branches, each possibly a different basic
               topology (star/ring/bus). Common in WANs linking many LANs.

10.6 Identifying Nodes in a Network

MAC Address — physical, permanent
- "Media Access Control" address, engraved on the NIC at manufacture
- 12-digit hexadecimal (48 bits): first 6 digits = manufacturer's OUI,
  last 6 digits = unique serial number
- CANNOT be changed -- permanently identifies the physical machine

Example:  FC:F8:AE:CE:7B:16
          \_______/\_______/
            OUI      Serial Number
IP Address — logical, can change
IPv4: 32-bit, four decimal numbers (0-255) separated by dots
      e.g. 192.168.0.178   -- ~4.3 billion unique addresses (not enough!)

IPv6: 128-bit, eight groups of hexadecimal separated by colons
      e.g. 2001:CDBA:0000:0000:0000:0000:3257:9652

Key difference from MAC: IP address CAN change if a device moves
from one network to another.

10.7 Internet, Web and the Internet of Things

The Internet is the global network connecting computers, phones, servers, and increasingly smart appliances and IoT devices. Devices connect to a modem → local ISP → regional network → national network → the Internet backbone.

World Wide Web — three technologies Tim Berners-Lee defined in 1990
HTML  HyperText Markup Language -- designs standardised web pages
URI/URL  Uniform Resource (Identifier/Locator) -- a page's unique address
         http://www.ncert.nic.in/textbook/textbook.htm
         \_________Domain Name_________/\____path____/
HTTP  HyperText Transfer Protocol -- rules for retrieving linked web
      pages. HTTPS is the more secure, advanced version.
Internet ≠ Web — a classic exam question

The Internet is the huge global network of interconnected computers (which may or may not share any file). The Web is the interlinked collection of webpages accessible over that Internet. The Internet is the road network; the Web is the destinations on it.

10.8 Domain Name System (DNS)

Every server has a numeric IP address, hard for humans to remember — so each server is given a human-friendly domain name instead, like a phonebook mapping names to numbers.

Table 10.1 — domain names mapped to IP addresses
ncert.nic.in      164.100.60.233
cbse.nic.in       164.100.107.32
mhrd.gov.in       164.100.163.45
wikipedia.org     198.35.26.96

Converting a domain name to its IP address is called domain name resolution, performed by a DNS server: when you enter a URL, HTTP in your browser asks a DNS server for the matching IP, then fetches the page from that address. DNS servers are hierarchical — at the top sit 13 root servers (named A through M), below them other DNS servers that either know a domain's IP directly or point to another server that does.

8. Exercise (from the textbook)

NCERT Exercise, Chapter 10

Work through these on paper

  1. Expand: (a) ARPANET, (b) MAC, (c) ISP, (d) URI.
  2. What do you understand by the term network? Mention two main advantages of using a network of computing devices.
  3. Differentiate between LAN and WAN. Name a few commonly used networking devices.
  4. Two universities in different states want to transfer information — which type of network should they use?
  5. Define topology. What are the popular network topologies? How is tree topology different from bus topology?
  6. Identify the topology: (a) each node connected with a single shared cable, (b) each node connected to central switching through independent cables.
  7. What is a modem? Why is it used? Explain: switch, repeater, router, gateway, NIC.
  8. Draw a network layout of star topology and bus topology connecting five computers.
  9. What is the significance of a MAC address? How is an IP address different from a MAC address?
  10. What is DNS? What is a DNS server?
  11. Sahil, a class X student, is confused between "World Wide Web" and "Internet." Help him understand both terms with suitable examples.
