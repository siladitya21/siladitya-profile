Chapter 7: Understanding Data

Based on NCERT's Class XII Computer Science textbook. Before databases and SQL, this chapter steps back to ask what data actually is: structured vs. unstructured, how it's collected, stored and processed, and the statistical techniques — mean, median, mode, range and standard deviation — used to summarise it into something a human can actually act on.

Chapter 7 of 13 NCERT pp. 97–110 ~2–3 Hours Exercise Included

By the end of this chapter, you'll be able to

  • Classify data as structured or unstructured, and explain metadata
  • Walk through the input → processing → output data cycle for a real scenario
  • Calculate mean, median, mode, range and standard deviation by hand

7.1 Introduction to Data

Data is a collection of characters, numbers and other symbols representing values of some situation or variable — the singular of "data" is "datum." On its own, raw data (like 2,000 placement records) doesn't tell you anything; it has to be processed and analysed before it supports a decision.

7.1.2 Types of Data

  • Structured data — organised in a well-defined, tabular (rows/columns) format; each column is an attribute, each row an observation. E.g. a shop's inventory table, or StudentName, Class, RollNo, FeesAmount, DepositDate for fee records.
  • Unstructured data — no fixed row/column pattern: newspaper layouts, emails, web pages, social media posts, documents, audio/video. Described using metadata ("data about data") — e.g. an email's subject/recipient/attachment fields, or an image's size/type/resolution.

7.2 Data Collection

Before processing, data must be gathered — either digitising paper records (diary → spreadsheet), using data already in digital form (a CSV file), or building new software (in Python, say) to collect and store it via a CSV file or a DBMS like MySQL. Hospitals, shopping malls, social media platforms, the World Bank and IMF all continuously collect data for their own decision-making.

7.3 Data Storage

Data is kept for future use on storage devices — HDD, SSD, CD/DVD, tape drive, pen drive, memory card. We store it as files, but plain file processing has limitations (covered properly in Chapter 8) that a Database Management System (DBMS) overcomes.

7.4 Data Processing

The data processing cycle turns raw data into usable information:

The data process cycle
INPUT                   PROCESSING              OUTPUT
Data Collection    →    Store, Retrieve,    →    Reports,
Data Preparation        Classify, Update         Results,
Data Entry                                       Processing System

RAW DATA (numbers/text/image) --Data Processing--> INFORMATION (table/chart/text)

Example — issuing a train ticket: Input = journey details, class, berth preference, payment info. Processing = verify login, check berth availability, deduct from available tickets, allocate PNR. Output = a confirmed ticket with berth/coach number, or a waiting-list number.

7.5 Statistical Techniques for Data Processing

7.5.1 Measures of Central Tendency

A single value that summarises a data set — mean, median or mode.

(A) Mean — the average
mean = (sum of all n values) / n

Heights (cm): [90,102,110,115,85,90,100,110,110]
mean = (90+102+110+115+85+90+100+110+110) / 9 = 912/9 = 101.33 cm

Mean is unsuitable when the data has outliers (exceptionally large/small values) — remove them first, then compute mean on the rest.

(B) Median — the middle value, once sorted
Sorted heights: [85,90,90,100,102,110,110,110,115]   (9 values, odd count)
median = value at position 5 = 102 cm

-- even count: median = average of the two middle values
(C) Mode — the most frequent value
In [90,102,110,115,85,90,100,110,110], 110 occurs 3 times --
more than any other value, so mode = 110.
-- A data set with every value appearing once has no mode.
-- More than one value can tie for mode (multimodal).

7.5.2 Measures of Variability

How spread out the data is — Range and Standard Deviation.

(A) Range
Range = Maximum - Minimum

Heights: max = 115, min = 85  →  Range = 115 - 85 = 30 cm

Range only uses the two extremes, so an outlier badly distorts it.

(B) Standard deviation — spread around the mean, using every value
σ = sqrt( Σ(xi - mean)^2 / n )

For the 9 heights (mean = 101.33):
Σ(xi - mean)^2 = 938.00
σ = sqrt(938.00 / 9) = sqrt(104.22) ≈ 10.2 cm

Smaller σ → data clustered tightly around the mean. Larger σ → data more spread out. Unlike Range, standard deviation accounts for every value, not just the extremes.

Picking the right technique — exam pattern

"Disparity in salaries" → Standard Deviation or Range. "Average class performance" → Mean. "Dominant/most common value" → Mode. "Middle-ranked value, resistant to outliers" → Median.

6. Exercise (from the textbook)

NCERT Exercise, Chapter 7

Work through these conceptually

  1. Identify the data needed for: (a) declaring exam results/e-certificates, (b) registering exhibition participants with biometric IDs, (c) an image search engine, (d) booking a hospital OPD appointment.
  2. A school of 500 students wants a merit-cum-means scholarship list (>75% for 2 consecutive years, family income < ₹5 lakh/year). Describe the data processing steps.
  3. A bank wants to gauge its popularity in a city by accounts-per-family and average monthly balance. Describe the data collection steps and what the processing could reveal.
  4. Classify the data type generated by: (a) recording a video, (b) a teacher marking attendance, (c) writing tweets, (d) filling an online application form.
  5. For a week's temperatures (°C): 34, 34, 27, 28, 27, 34, 34 — find (a) the average, (b) the range, (c) the standard deviation.
  6. A teacher wants to: (a) compare division secured between two equal-strength classes, (b) compare class performance across five monthly unit tests. Identify the right statistical technique for each, with justification.
  7. For a school honouring parents who are alumni: (a) which technique counts students with both parents as alumni? (b) which technique measures how varied the parents' ages are?
  8. Selecting an anchor from 42 students by singing/writing/monitoring skill: (a) what data collection mode would you use? (b) how would you represent "skill" as data?
  9. Differentiate structured vs. unstructured data with an example. Then, for a school canteen's purchase/sale data:
    • Compare purchase vs. sale price of fruit juice and biscuits.
    • Compare sales of fruit juice, biscuits and samosa.
    • Compare sale-price variation of fruit juices across companies for the same quantity.
    Create a sample dataset and apply the right statistical technique to each comparison.
