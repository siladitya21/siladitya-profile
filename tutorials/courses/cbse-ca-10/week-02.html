Chapter 2: HTML — Structure & Text Formatting

Based on the official CBSE Computer Applications (165) curriculum, Unit 2 — the largest unit in the syllabus (25 marks, 30 theory + 50 practical periods). This chapter builds your very first web page: the html/head/body skeleton, headings and text formatting, lists, and images — everything needed before tables, forms and CSS in the chapters that follow.

Chapter 2 of 6 Unit 2, Part A ~3 Hours Hands-on Exercise Included

By the end of this chapter, you'll be able to

  • Write the correct html/head/body skeleton and save/open it as a web page
  • Format text with headings, bold/italic/underline, and the font tag's attributes
  • Build ordered, unordered and description lists, and insert images correctly

2.1 Introduction to Web Page Designing Using HTML

HTML (HyperText Markup Language) describes a web page's structure using tags — keywords in angle brackets. Most tags come in pairs: an opening tag <tag> and a matching closing tag </tag>, with content in between. A few tags (like <br>) are empty/self-closing — no closing tag needed.

The minimum skeleton every HTML page needs
<html>
<head>
    <title>My First Web Page</title>
</head>
<body>
    <p>Hello, World! This is my first web page.</p>
</body>
</html>
What each tag does
<html>   the ROOT tag -- everything on the page goes inside it
<head>   holds information ABOUT the page (not shown in the page body)
<title>  the text shown in the browser tab / window title bar
<body>   holds everything that's actually DISPLAYED on the page
Create, save and open — the practical workflow

Type the code in any plain text editor (Notepad is fine), save the file with a .html extension (e.g. myfirstpage.html), then double-click the saved file — it opens directly in your default browser. No server or installation needed.

2.2 The body Tag's Colour Attributes

Attributes that control the whole page's appearance
<body text="blue" bgcolor="lightyellow" link="green" vlink="purple" alink="red">

text        colour of all ordinary page text
background  an IMAGE used as the page's background
bgcolor     a plain COLOUR used as the page's background
link        colour of an UNVISITED hyperlink
vlink       colour of a VISITED hyperlink
alink       colour of a link at the moment it's being ACTIVELY clicked
Worked example
<body bgcolor="#f0f8ff" text="navy" link="darkgreen" vlink="purple">
    <p>Welcome to my homepage.</p>
</body>

2.3 br, hr and Comments

br (line break) and hr (horizontal rule) — both empty tags
<p>Line one<br>Line two<br>Line three</p>
<!-- <br> forces a new line WITHOUT starting a new paragraph -->

<hr>
<!-- <hr> draws a horizontal line across the page, often used
     to visually separate sections of content -->
Inserting comments — never shown on the rendered page
<!-- This is a comment. The browser ignores everything inside it. -->
<p>This text IS shown.</p>

2.4 Headings and Text Formatting Tags

Six levels of heading — h1 (largest/most important) to h6 (smallest)
<h1>This is a Main Heading</h1>
<h2>This is a Sub-heading</h2>
<h3>A smaller heading still</h3>
...
<h6>The smallest heading</h6>

<p>This is a normal paragraph of body text.</p>
Character-level formatting — bold, italics, underline
<b>This text is bold</b>
<i>This text is italic</i>
<u>This text is underlined</u>

<p>You can <b>combine <i>bold and italic</i> together</b> in one line.</p>

2.5 The font Tag

font (face, size, color) — three attributes
<font face="Arial" size="5" color="crimson">
    Styled text using the font tag.
</font>

face   the font FAMILY to use (e.g. Arial, Times New Roman, Verdana)
size   a number from 1 (smallest) to 7 (largest) -- NOT a pixel value
color  the text colour, as a named colour ("red") or a hex code ("#FF0000")
Worth knowing, even though it's in the syllabus

The font tag still appears in the CBSE 165 syllabus and will be asked in the exam — but in modern real-world web development, text styling (family/size/colour) is done with CSS instead (Chapter 4), which is far more flexible.

2.6 Lists — Ordered, Unordered & Description

Unordered list (ul) — bulleted, no inherent order
<ul type="square">
    <li>Apples</li>
    <li>Bananas</li>
    <li>Cherries</li>
</ul>
<!-- ul's type attribute: disc (default), circle, square -->
Ordered list (ol) — numbered, sequence matters
<ol start="3" type="A">
    <li>Third item</li>
    <li>Fourth item</li>
    <li>Fifth item</li>
</ol>
<!-- renders as: C. Third item  D. Fourth item  E. Fifth item -->

<!-- ol's start attribute: the number/letter to begin counting from
     ol's type attribute: 1 (default numbers), A, a, I, i (roman numerals) -->
Description list (dl, dt, dd) — term + definition pairs
<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language -- used to structure web pages.</dd>
    <dt>CSS</dt>
    <dd>Cascading Style Sheets -- used to style web pages.</dd>
</dl>

dl  wraps the WHOLE description list
dt  the TERM being described
dd  the DESCRIPTION/definition of that term (usually indented)

2.7 Images, Superscript and Subscript

img (src, width, height, alt) — an empty tag
<img src="logo.png" width="200" height="100" alt="Company Logo">

src     the image file's PATH or URL (required)
width   display width in pixels
height  display height in pixels
alt     ALTERNATE TEXT shown if the image fails to load, and read
        aloud by screen readers for accessibility
sup (superscript) and sub (subscript)
E = mc<sup>2</sup>          <!-- renders as: E = mc² -->
H<sub>2</sub>O               <!-- renders as: H₂O -->
Putting it together — a complete small page
<html>
<head><title>About Water</title></head>
<body bgcolor="white" text="black">
    <h1>Facts About Water</h1>
    <hr>
    <p>Water's chemical formula is <b>H<sub>2</sub>O</b>.</p>
    <img src="water.jpg" width="300" height="200" alt="A glass of water">
    <h2>States of Water</h2>
    <ul>
        <li>Solid (ice)</li>
        <li>Liquid</li>
        <li>Gas (water vapour)</li>
    </ul>
</body>
</html>

8. Exercise (exam-style, based on the CBSE curriculum)

Unit 2 Practice Questions (Part A)

Work through these, then verify by opening the HTML in a browser

  1. Name the three mandatory tags every HTML page should have, and explain the role of each.
  2. What is the difference between the head and body sections of an HTML page?
  3. Write the body tag with attributes to set the text colour to white and the background colour to black.
  4. What is the difference between <br> and <hr>?
  5. Write HTML to display your name as a heading, followed by a horizontal rule, followed by a short paragraph about yourself.
  6. Write the font tag to display the text "Welcome" in Verdana, size 6, in blue.
  7. Write an ordered list of your top 3 favourite subjects, numbered using roman numerals, starting from 1.
  8. Write a description list (dl/dt/dd) defining any three HTML tags covered in this chapter.
  9. Write the img tag to insert an image named photo.jpg, 150px wide, 150px tall, with appropriate alternate text.
  10. Write the HTML to correctly display the chemical formula for carbon dioxide (CO₂) and the mathematical expression a³.
