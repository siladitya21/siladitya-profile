Chapter 4: Cascading Style Sheets (CSS)

Based on the official CBSE Computer Applications (165) curriculum, Unit 2 (final part). Every page built in Chapters 2–3 used HTML's own colour/font attributes — CSS replaces all of that with one proper styling language. This chapter covers how to attach CSS to a page three ways, and the exact property list the syllabus names: colour, background-colour, border-style, margin, height, width, outline, font, align and float.

4.1 What is CSS?

Cascading Style Sheets (CSS) describes how HTML elements should look — colours, fonts, spacing, borders, layout — kept separate from the HTML that describes a page's content and structure. The word "cascading" means styles can come from multiple places at once, with clear rules deciding which one wins when they conflict.

CSS rule syntax
selector {
    property: value;
    property: value;
}

/* example */
p {
    color: blue;
    font-size: 16px;
}

4.2 Three Ways to Attach CSS to a Page

Inline CSS — directly on ONE element, via the style attribute
<p style="color: red; font-size: 20px;">This paragraph is styled inline.</p>
Internal CSS — inside a style tag in the head, affects the WHOLE page
<head>
<style>
    body { background-color: #f4f4f4; }
    h1 { color: darkblue; text-align: center; }
</style>
</head>
External CSS — a separate .css file, linked to ANY number of pages
<!-- in the HTML file's <head> -->
<link rel="stylesheet" href="style.css">

/* in the separate file style.css */
body { background-color: #f4f4f4; }
h1 { color: darkblue; text-align: center; }
Which one to use — and which wins when they clash

External is best for a multi-page site (one file styles every page). Internal suits a single, self-contained page. Inline is for one-off overrides. When styles conflict: Inline beats Internal, which beats External — the more specific/closer-to-the-element rule wins.

4.3 Colour and Background-colour

Setting text colour vs. background colour
h1 {
    color: white;              /* the TEXT colour */
    background-color: teal;    /* the colour BEHIND the text/element */
}

/* colours can be named, hex, or rgb() */
p { color: #336699; }
div { background-color: rgb(240, 240, 240); }

4.4 Border, Margin, Height, Width, Outline

border-style — the line drawn around an element
div {
    border-style: solid;   /* also: dashed, dotted, double, none */
    border-width: 2px;
    border-color: black;
}
margin — space OUTSIDE an element's border
div {
    margin: 20px;              /* same 20px on all 4 sides */
    margin: 10px 20px;         /* 10px top/bottom, 20px left/right */
}
height and width — the element's dimensions
img {
    width: 300px;
    height: 200px;
}
outline — a line drawn AROUND the border (doesn't affect layout space)
input {
    outline: 2px dotted blue;
}
Border vs. outline — the exact difference

Border sits right at the edge of an element and takes up layout space (pushes neighbouring content). Outline is drawn on top, around the border, but never affects the page's layout — it can even overlap neighbouring elements.

4.5 Font, Align and Float

font — family, style, size (replaces HTML's font tag)
p {
    font-family: "Times New Roman", serif;
    font-style: italic;       /* also: normal, oblique */
    font-size: 18px;
}
align (text-align) — horizontal alignment of content
h1 { text-align: center; }    /* also: left, right, justify */
float — pulls an element to one side, letting content flow around it
img {
    float: left;      /* also: right, none */
    margin-right: 10px;   /* a little spacing so text doesn't touch it */
}
<!-- A classic use: a small image floated left, with a paragraph of
     text wrapping around it on the right, newspaper-style. -->
A complete worked example — restyling Chapter 2's water page with CSS
<html>
<head>
<title>About Water</title>
<style>
    body { background-color: #eaf6ff; font-family: Arial, sans-serif; }
    h1 { color: navy; text-align: center; }
    img { float: left; margin-right: 15px; border-style: solid;
          border-width: 2px; border-color: navy; width: 150px; height: 100px; }
    ul { color: darkslategray; }
</style>
</head>
<body>
    <h1>Facts About Water</h1>
    <img src="water.jpg" alt="A glass of water">
    <p>Water's chemical formula is H<sub>2</sub>O.</p>
    <ul>
        <li>Solid (ice)</li>
        <li>Liquid</li>
        <li>Gas (water vapour)</li>
    </ul>
</body>
</html>

6. Exercise (exam-style, based on the CBSE curriculum)

Unit 2 Practice Questions (Part C)

Work through these, then verify by opening the HTML in a browser

  1. Differentiate between inline, internal and external CSS, with an example of when you'd choose each.
  2. If an element has both an inline style and an internal style conflicting, which one applies? Why?
  3. Write internal CSS to make all h2 headings green, centre-aligned, in the Verdana font.
  4. Write CSS to give a div a 3px dashed red border, 15px margin on all sides, and a width of 400px.
  5. What is the difference between border and outline?
  6. Write CSS to float an image to the right of a paragraph, with a 10px left margin so text doesn't touch it.
  7. Create an external stylesheet file that sets the page background colour to light grey and all paragraph text to dark blue; then write the HTML line that links this stylesheet to a page.
  8. Rewrite this HTML-attribute-styled line using CSS instead: <font face="Arial" size="5" color="red">Notice</font>.
  9. Write CSS to give all form input elements a 2px solid blue outline and a 5px margin.
  10. Take your table + form page from Chapter 3's exercises and add an internal style sheet that: centres the table headings, colours the table border, and right-aligns the form's labels.
