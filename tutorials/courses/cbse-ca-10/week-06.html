Chapter 6: Practicals & Project Guide

Based on the official CBSE Computer Applications (165) curriculum — the Practicals component, worth 50 of the exam's 100 marks, exactly as much as all three theory units combined. This final chapter maps out precisely how those 50 marks are earned, lists every official lab exercise, and walks through a complete sample project.

  • Prepare a report file of at least 10 HTML pages covering every official lab exercise
  • Plan and build a small multi-page project website combining HTML, CSS and forms

1. The Official 50-Mark Breakdown

Exactly as specified in the CBSE 165 curriculum
COMPONENT                        MARKS
Lab Test (design a page from a
  given diagram)                    20
Report File (at least 10 HTML
  pages) + Viva Voce               15 + 5  = 20
Project (uses most concepts
  learnt in the course)             10
                                   ------
TOTAL PRACTICAL MARKS               50

2. The Lab Test (20 Marks)

You're given a diagram or printed layout of a web page during the exam and must recreate it in HTML in the lab, on the spot.

What examiners typically check
- Does the page STRUCTURE match the diagram (headings, paragraphs,
  images in the right place)?
- Are COLOURS and TEXT FORMATTING applied as shown?
- If a table or form appears in the diagram, is it correctly built
  (right number of rows/columns, correct input types)?
- Is the code syntactically correct (opening/closing tags, proper
  nesting)?
- Does the page actually RENDER and look reasonably close to the
  diagram when opened in a browser?
How to prepare

Practice recreating random layouts (ads, posters, notice boards, timetables you see around you) in plain HTML under a time limit. The skill being tested is translating a visual layout into the right combination of tags from Chapters 2–4, quickly and correctly.

3. Report File + Viva Voce (20 Marks)

Report file requirement
- AT LEAST 10 HTML pages, printed (or saved) and bound together
- Should demonstrate a WIDE RANGE of tags/concepts from Chapters 2-4
  -- not 10 pages that all do the same thing
- Typically includes: the HTML source code printout AND a screenshot/
  printout of how the page looks in a browser, side by side
A good spread of 10 pages — one possible plan
1.  Basic page: headings, paragraphs, br/hr, comments
2.  Text formatting: bold/italic/underline, font tag
3.  Unordered + ordered lists (with type/start attributes)
4.  Description list of 5 technical terms
5.  Images with sup/sub (a science-fact page)
6.  A table with rowspan AND colspan both used
7.  A form using every input type: text, radio, checkbox, password
8.  A form with a combobox and a multi-select list box
9.  A page with internal CSS: colours, border, margin, font
10. A page with an embedded audio or video, plus links (internal +
    mailto) to tie the whole site together

Viva voce (5 of the 20 marks) is an oral exam based on your report file — expect questions like "what does this attribute do," "why did you use a colspan here," or "what's the difference between this tag and that one." Know your own pages well enough to explain every line.

4. The Official Lab Exercise List

These are the exact lab exercises named in the CBSE curriculum document — your report file pages should collectively cover all of them.

From the curriculum, verbatim topics
- Create static web pages
- Use style sheets to enforce a format in an HTML page (CSS)
- Embed pictures, audio and videos in an HTML page
- Add tables and frames in an HTML page
- Decorate web pages using graphical elements
- Create a website using several web pages (any open source or
  proprietary tool is allowed)
- Work with HTML forms: text box, radio buttons, checkbox, password,
  list, combo box
- Write a blog using HTML pages discussing viruses, malware, spam
  and antiviruses
- Create a web page discussing plagiarism -- list some reported
  cases and the resulting punishment, including how different
  countries' IP laws treat it differently
The last two items connect Units 2 and 3 directly

Notice the "blog on viruses/malware" and "plagiarism page" exercises — they're HTML exercises (Unit 2 skills) with Cyber Ethics content (Unit 3, Chapter 5). The curriculum deliberately ties the units together in the practical component.

5. The Project (10 Marks)

The project should use most of the concepts learnt in the course — it's meant to be a small but complete multi-page website, not a single isolated page.

What a strong project typically includes
- At least 3-5 linked pages (a home page + a few content pages)
- Consistent navigation -- every page links back to the others
- At least one table AND one form somewhere in the site
- A consistent look across pages -- ideally via an EXTERNAL
  stylesheet shared by all pages (Chapter 4)
- A clear, specific THEME rather than random unrelated content

6. A Worked Sample Project — "My School" Website

A simple theme that naturally uses tables, forms, images, links and CSS together:

Suggested page plan
index.html        Home page: school name/logo image, a short welcome
                  paragraph, navigation links to the other 3 pages
about.html        About the school: history, an image, a description
                  list of key facts (founded, motto, principal)
timetable.html    A table showing a sample weekly timetable, using
                  colspan for a "Monday-Friday" header row
contact.html      A contact form (name, email-style text box, a
                  dropdown for "reason for contact", a message box)
                  PLUS a mailto: link and an embedded location note
style.css         ONE external stylesheet, linked from all 4 pages,
                  giving a consistent background colour, heading
                  colour, and navigation link styling
The shared navigation block (repeated identically on every page)
<p>
    <a href="index.html">Home</a> |
    <a href="about.html">About</a> |
    <a href="timetable.html">Timetable</a> |
    <a href="contact.html">Contact</a>
</p>
<hr>

This single small project exercises tags/concepts from every chapter in this course — structure and text (Ch. 2), tables/forms/links (Ch. 3), shared CSS (Ch. 4) — which is exactly what "uses most of the concepts learnt" means in practice.

7. Final Preparation Checklist

Before Your Practical Exam

Work through this checklist, building each item as a real HTML file

  1. Build and open in a browser: a page using every tag from Chapter 2 (headings, b/i/u, font, lists, images with sup/sub).
  2. Build a table combining both rowspan and colspan in the same table.
  3. Build one form that includes all six input types named in the syllabus: textbox, radio, checkbox, password, list, combobox.
  4. Build a page with an embedded audio or video file, plus at least one internal link and one mailto: link.
  5. Write an external stylesheet and link it from two different HTML pages, confirming both pick up the same styling.
  6. Write the "virus/malware blog" lab exercise page, and the "plagiarism" lab exercise page, from the official list above.
  7. Assemble your 10-page report file plan — list which tags/concepts each page demonstrates, making sure nothing from Chapters 2–4 is missing.
  8. Build the 4-page sample project above (or your own themed equivalent), with a shared external stylesheet and consistent navigation.
  9. Rehearse explaining 3 of your report-file pages out loud, as if answering viva questions — what each tag does and why you chose it.
  10. Review Chapter 1 (Networking) and Chapter 5 (Cyber Ethics) theory questions one more time — together they're 25 of the 50 theory marks.

Course complete

You've covered all three units and the full practical structure

Networking, HTML (structure through CSS), and Cyber Ethics — the complete theory syllabus — plus exactly how the 50 practical marks are earned. If you continue to Class 11–12 Computer Science, you'll find the HTML/web knowledge here is a useful (though separate) foundation — those courses move into full programming with Python, data structures and databases.
