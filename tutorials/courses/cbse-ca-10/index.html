A chapter-by-chapter walkthrough built directly from the official CBSE curriculum for Class X Computer Applications (Code 165) — Internet & networking fundamentals, building web pages with HTML from the ground up through forms and tables, styling them with CSS, cyber ethics, and a full guide to the practical exam's lab test, report file and project component.

Before You Start

Prerequisites & tooling

What you should already know

  • Basic computer familiarity — files, folders, using a web browser
  • No prior programming or web design experience required
  • A text editor (Notepad, Notepad++, or VS Code) and any web browser
  • No server setup needed — every HTML file in this course runs by just opening it in a browser

The three units this course covers

Exactly as weighted in the official CBSE curriculum (165).

Unit 1: Networking (15 marks) Unit 2: HTML (25 marks) Unit 3: Cyber Ethics (10 marks) Practicals (50 marks)
Syllabus

6 chapters, matched to the official CBSE unit weightage

HTML is the largest unit by far (30 theory + 50 practical periods), so it's split across two lessons here.

01
CHAPTER 1 · UNIT 1

Networking

The Internet, its protocols, web services and mobile technologies.

  • WWW, web servers/clients/sites/pages/browsers, blogs, downloading/uploading
  • Internet protocols — TCP/IP, SMTP, POP3, HTTP/HTTPS, SSH, SFTP, FTP, TELNET
  • Web services (e-Learning, e-Banking, e-Governance...) & mobile tech (SMS/MMS/3G/4G)
Start this lesson
02
CHAPTER 2 · UNIT 2 (PART A)

HTML — Structure & Text Formatting

Your first web page: document structure, headings, text tags, lists, images.

  • html, head, title, body & the body colour attributes
  • Headings, paragraphs, br/hr, bold/italic/underline, font
  • Ordered/unordered/description lists, img, sup/sub
Start this lesson
03
CHAPTER 3 · UNIT 2 (PART B)

HTML — Tables, Forms, Links & Media

The interactive and structural tags that make a real website.

  • Tables — table, tr, th, td, rowspan/colspan
  • Forms — textbox, radio, checkbox, password, list, combobox
  • Anchor links (href, mailto, targets) & embedding audio/video
Start this lesson
04
CHAPTER 4 · UNIT 2 (PART C)

Cascading Style Sheets (CSS)

Beautifying the web pages built in Chapters 2 and 3.

  • Inline, internal & external style sheets
  • Colour, background-colour, border-style, margin, height, width, outline
  • font (family/style/size), align, float
Start this lesson
05
CHAPTER 5 · UNIT 3

Cyber Ethics

Being a responsible, informed user of the Internet.

  • Netiquettes & software licenses (open source movement)
  • IPR, plagiarism & digital property rights
  • Freedom of information, digital divide & e-commerce safety
Start this lesson
06
CHAPTER 6 · PRACTICALS (50 MARKS)

Practicals & Project Guide

Exactly how the 50 practical marks are earned, and how to prepare for each part.

  • Lab Test (20) — designing a web page from a given diagram
  • Report File + Viva (20) — at least 10 HTML pages, with viva prep
  • Project (10) — a multi-page website combining everything learnt
