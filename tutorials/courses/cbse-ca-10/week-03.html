Chapter 3: HTML — Tables, Forms, Links & Media

Based on the official CBSE Computer Applications (165) curriculum, Unit 2 (continued). With the basics from Chapter 2 in place, this chapter covers the tags that turn a page into something properly structured and interactive: tables for tabular data, forms for user input, hyperlinks for navigation between pages, and embedding audio and video directly in the page.

Chapter 3 of 6 Unit 2, Part B ~3 Hours Hands-on Exercise Included

By the end of this chapter, you'll be able to

  • Build a table with merged cells using rowspan and colspan
  • Create every common form input type the syllabus lists
  • Link between pages, link to an email address, and embed audio/video

3.1 Creating a Table

table, tr, th, td — the four core tags
<table border="1">
    <tr>
        <th>Name</th>
        <th>Subject</th>
        <th>Marks</th>
    </tr>
    <tr>
        <td>Ravi</td>
        <td>Computer Applications</td>
        <td>92</td>
    </tr>
    <tr>
        <td>Priya</td>
        <td>Mathematics</td>
        <td>88</td>
    </tr>
</table>

table  wraps the WHOLE table
tr     one TABLE ROW
th     a TABLE HEADING cell (bold, centred by default)
td     an ordinary TABLE DATA cell

3.2 rowspan and colspan — merging cells

colspan — merges cells ACROSS columns (horizontally)
<table border="1">
    <tr>
        <th colspan="3">Term 1 Report Card</th>
    </tr>
    <tr>
        <td>English</td><td>Hindi</td><td>Science</td>
    </tr>
</table>
<!-- the colspan="3" header cell stretches across all 3 columns below it -->
rowspan — merges cells DOWN rows (vertically)
<table border="1">
    <tr>
        <td rowspan="2">Class X</td>
        <td>Section A</td>
    </tr>
    <tr>
        <td>Section B</td>
    </tr>
</table>
<!-- "Class X" spans down both rows -- only ONE <td> is needed per
     merged cell, so the second row has ONE FEWER <td> than normal -->

3.3 HTML Forms

Forms collect input from the user — every input type listed in the syllabus:

Textbox, Radio buttons, Checkbox, Password
<form>
    Name: <input type="text" name="uname"><br><br>

    Gender:
    <input type="radio" name="gender" value="M"> Male
    <input type="radio" name="gender" value="F"> Female<br><br>

    Hobbies:
    <input type="checkbox" name="hobby" value="reading"> Reading
    <input type="checkbox" name="hobby" value="sports"> Sports<br><br>

    Password: <input type="password" name="pwd">
</form>

TEXT BOX   <input type="text"> -- single-line free text entry
RADIO      <input type="radio"> -- pick EXACTLY ONE from a group
           (same "name" attribute groups radio buttons together)
CHECKBOX   <input type="checkbox"> -- pick ANY NUMBER of options
PASSWORD   <input type="password"> -- text entry, characters MASKED
List and Combobox — the select element
<!-- COMBOBOX: a dropdown showing ONE option at a time -->
<select name="city">
    <option value="del">Delhi</option>
    <option value="kol">Kolkata</option>
    <option value="mum">Mumbai</option>
</select>

<!-- LIST BOX: the same select element, but "size" shows several
     options at once, and multiple selects multiple choices -->
<select name="subjects" size="3" multiple>
    <option value="eng">English</option>
    <option value="math">Mathematics</option>
    <option value="sci">Science</option>
    <option value="ca">Computer Applications</option>
</select>

3.4 Links — The Anchor Element

Linking is what makes the Web a web — the ability to jump from one page (or resource) to another makes documents interconnected rather than isolated.

The anchor tag — href, mailto, target
<!-- linking to another page -->
<a href="about.html">About Us</a>

<!-- linking to an external website -->
<a href="https://www.cbse.gov.in">CBSE Official Site</a>

<!-- linking to an email address -->
<a href="mailto:someone@example.com">Email Us</a>

<!-- opening the link in a NEW browser tab/window -->
<a href="https://www.cbse.gov.in" target="_blank">CBSE (new tab)</a>

href     the DESTINATION of the link (a page, a URL, or mailto:address)
mailto:  a special href value that opens the user's email client
target   where to open the link -- "_blank" = new tab, "_self" = same tab (default)

3.5 Embedding Audio and Video

The audio and video tags, with playback controls
<audio controls>
    <source src="anthem.mp3" type="audio/mpeg">
    Your browser does not support the audio tag.
</audio>

<video width="400" height="300" controls>
    <source src="demo.mp4" type="video/mp4">
    Your browser does not support the video tag.
</video>

controls   shows the browser's built-in play/pause/volume controls
source     the actual media file; you can list several formats as a
           fallback -- the browser plays the first one it supports
Putting a table + form + links together — a realistic practical task

A typical lab question combines all of this chapter's tags in one page: a results table with merged header cells, a feedback form below it with a few input types, and a link back to the home page — exactly the kind of page the Lab Test asks you to build from a diagram (covered in Chapter 6).

6. Exercise (exam-style, based on the CBSE curriculum)

Unit 2 Practice Questions (Part B)

Work through these, then verify by opening the HTML in a browser

  1. Write HTML for a 3×3 table (with a header row) showing your weekly class timetable for any 2 days.
  2. Create a table where one header cell spans 4 columns to show the title "Monthly Fee Structure," with a data row below it.
  3. Create a table listing 3 students, where "Class X" is shown once using rowspan for 2 students in the same class.
  4. Write a feedback form with: a text box for name, radio buttons for "Satisfied/Not Satisfied," a checkbox list of 3 reasons, and a password field.
  5. Write a dropdown (combobox) listing 4 Indian states, and a list box (multi-select) listing 4 hobbies.
  6. What is the difference between a combobox and a list box, in terms of the select tag's attributes?
  7. Write an anchor tag that links to a page called contact.html, opening it in a new tab.
  8. Write an anchor tag that opens the user's email client addressed to info@myschool.edu.
  9. Write HTML to embed an audio file called song.mp3 with visible playback controls.
  10. Design a web page with a table of 3 products and prices, and a link at the bottom back to a page called home.html.
