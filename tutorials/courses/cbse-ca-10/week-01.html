Chapter 1: Networking

Based on the official CBSE Computer Applications (165) curriculum, Unit 1 — 15 marks. Before building a single web page, this chapter covers what the Internet actually is, the protocols that quietly run it, the everyday services built on top of it, and the mobile technologies that carry it in your pocket.

Chapter 1 of 6 Unit 1 — 15 Marks ~2 Hours Exam-style Questions Included

By the end of this chapter, you'll be able to

  • Explain the difference between the Internet and the World Wide Web
  • Name each internet/file-transfer protocol and what it's used for
  • List common web services and mobile technologies with real examples

1.1 The Internet and the World Wide Web

Core terms from the curriculum
INTERNET      a global network connecting millions of computers/
              devices, allowing them to communicate with each other

WORLD WIDE WEB (WWW)
              the system of interlinked, hypertext documents (web
              pages) accessible OVER the Internet -- the Web runs ON
              the Internet, it is not the same thing as the Internet

WEB SERVER    a computer that stores and serves web pages on request
WEB CLIENT    the device/program (usually a browser) requesting pages
WEB SITE      a collection of related web pages under one domain
WEB PAGE      a single document viewable in a browser
WEB BROWSER   software used to access/view web pages (Chrome, Firefox, Edge)
BLOG          a regularly updated personal/informational web journal
NEWSGROUP     an online discussion group on a specific topic (Usenet-style)
HTML          HyperText Markup Language -- the language web pages are written in
WEB ADDRESS   a URL identifying a specific page/resource (e.g. https://example.com)
EMAIL ADDRESS a unique identifier for sending/receiving electronic mail
Downloading vs. Uploading
DOWNLOADING  transferring a file FROM a remote server TO your own device
UPLOADING    transferring a file FROM your own device TO a remote server
Internet vs. Web — the classic exam question

The Internet is the vast physical and logical network of connected computers worldwide. The Web is just one service that runs on top of it — the collection of linked hypertext pages you browse. Email, FTP and video calls all also run on the Internet, but aren't part of the Web.

1.2 Internet Protocols

A protocol is a set of rules that lets different computers communicate reliably.

Core internet protocols
TCP/IP   Transmission Control Protocol / Internet Protocol
         the foundational protocol suite the entire Internet runs
         on. IP handles addressing/routing; TCP breaks data into
         packets, ensures reliable, in-order delivery.

HTTP     HyperText Transfer Protocol -- how a browser requests and
         receives web pages from a server (plain, unencrypted)

HTTPS    HTTP Secure -- the same thing, but ENCRYPTED, so data (like
         passwords or card details) can't be read if intercepted in
         transit. Look for the padlock icon in the browser.

SMTP     Simple Mail Transfer Protocol -- used to SEND email

POP3     Post Office Protocol v3 -- used to RECEIVE/download email
         from a mail server to one device (removing it from the server)

1.2.1 Remote Login and File Transfer Protocols

Accessing and moving files on another computer
TELNET   lets you log in to and operate a REMOTE computer from your
         own, as if you were sitting at it -- plain text, NOT secure

SSH      Secure Shell -- does what Telnet does, but ENCRYPTED --
         the modern, secure replacement for Telnet

FTP      File Transfer Protocol -- the standard way to upload/
         download files to/from a remote server -- NOT encrypted

SFTP     SSH File Transfer Protocol -- FTP's data travels over an
         encrypted SSH connection -- the secure version of FTP

SCP      Secure Copy Protocol -- copies files between computers over
         SSH; simpler than SFTP, used mainly for quick, one-off transfers
The pattern worth remembering

HTTP → HTTPS, Telnet → SSH, FTP → SFTP: in each pair, the second protocol does exactly the same job as the first, but adds encryption. CBSE exam questions often ask you to name "the secure version of ___."

1.3 Services Available on the Internet

Finding information and people
INFORMATION RETRIEVAL    locating and extracting useful information
                         from the vast data available online

SEARCH ENGINES           tools (Google, Bing) that index web content
                         so you can locate relevant sites by keyword

FINDING PEOPLE ON THE NET   using social networks, directories, or
                            search engines to locate individuals online

1.4 Web Services

Everyday "e-" services built on the Internet
CHAT                 real-time text conversation between users
EMAIL                 sending/receiving electronic messages
VIDEO CONFERENCING    live audio-video communication between multiple parties
e-LEARNING            education delivered online (courses, LMS platforms)
e-BANKING             banking transactions conducted over the Internet
e-SHOPPING            buying/selling goods online (e-commerce)
e-RESERVATION         booking tickets/seats/rooms online (trains, hotels)
e-GOVERNANCE          government services delivered digitally to citizens
e-GROUPS              online communities built around a shared interest
SOCIAL NETWORKING     platforms connecting people to share content/ideas

1.5 Mobile Technologies

How phones send messages and connect to data
SMS   Short Message Service -- plain TEXT-only messages (160 chars/msg)
MMS   Multimedia Messaging Service -- messages with images/audio/video
3G    3rd Generation mobile network -- enabled mobile Internet/video calls
4G    4th Generation mobile network -- much faster data, HD streaming,
      the standard before 5G

7. Exercise (exam-style, based on the CBSE curriculum)

Unit 1 Practice Questions

Work through these on paper

  1. Differentiate between the Internet and the World Wide Web with an example of a service that uses one but not the other.
  2. What is the difference between a web server and a web client?
  3. Name the protocol used for: (a) sending email, (b) receiving email, (c) browsing a secure website, (d) transferring a file to a remote server securely.
  4. What does TCP/IP stand for, and what job does each part (TCP vs. IP) do?
  5. How is SSH different from Telnet? How is SFTP different from FTP?
  6. List any four web services and give one real-life example of each.
  7. What is the difference between SMS and MMS?
  8. Define: (a) downloading, (b) uploading, (c) search engine, (d) blog.
  9. Give two examples each of e-Governance and e-Reservation services you or your family have used.
  10. Why should a user prefer HTTPS over HTTP when entering a password or card number on a website?
