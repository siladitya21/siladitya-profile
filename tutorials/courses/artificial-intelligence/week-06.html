Week 6: Reasoning Under Uncertainty

Real agents rarely know the full state of the world — sensors are noisy and outcomes are uncertain. Logic says "true or false"; probability says "how likely". This week builds on the Bayes' theorem refresher in the Data Science tutorial and turns it into tools agents use: Bayesian networks, hidden Markov models and expected-utility decisions.

Phase 2 of 6 Week 6 of 19 ~3–4 Hours Hands-on Exercise Included

By the end of this week, you'll be able to

  • Model uncertain domains with Bayesian networks
  • Compute posterior probabilities with exact and sampling-based inference
  • Track hidden state over time and make decisions by expected utility

1. Bayesian Networks

A full joint probability table over n binary variables needs 2n entries — impossible beyond a handful of variables. A Bayesian network is a directed acyclic graph where each node depends only on its parents, so you store one small conditional table per node.

burglary network
Burglary   Earthquake
     \       /
       Alarm
     /       \
JohnCalls   MaryCalls

P(B)=0.001  P(E)=0.002
P(A | B,E): B,E=0.95  B,¬E=0.94  ¬B,E=0.29  ¬B,¬E=0.001
P(J | A)=0.90  P(J | ¬A)=0.05
P(M | A)=0.70  P(M | ¬A)=0.01

Ten numbers replace the 32-entry joint table. The joint probability of any full assignment is the product of each node's probability given its parents: P(b, e, a, j, m) = P(b)·P(e)·P(a | b, e)·P(j | a)·P(m | a).

2. Exact & Approximate Inference

Inference answers questions like "John and Mary both called — what's the probability of a burglary?" Enumeration sums the joint probability over all hidden variables:

enumeration.py
from itertools import product

P_B, P_E = 0.001, 0.002
P_A = {(True, True): .95, (True, False): .94, (False, True): .29, (False, False): .001}
P_J = {True: .90, False: .05}
P_M = {True: .70, False: .01}

def pr(p, value):
    return p if value else 1 - p

def joint(b, e, a, j, m):
    return (pr(P_B, b) * pr(P_E, e) * pr(P_A[(b, e)], a)
            * pr(P_J[a], j) * pr(P_M[a], m))

def p_burglary_given(j, m):
    num = sum(joint(True, e, a, j, m) for e, a in product([True, False], repeat=2))
    den = sum(joint(b, e, a, j, m) for b, e, a in product([True, False], repeat=3))
    return num / den

print(f"{p_burglary_given(True, True):.3f}")   # ~0.284

Even with both neighbors calling, a burglary is only about 28% likely, because burglaries are so rare to begin with — the base-rate effect from the statistics week, now computed automatically. Exact inference is exponential in the worst case, so large networks use sampling: generate many samples consistent with the evidence and count.

likelihood_weighting.py
import random

def weighted_sample(j, m):
    b = random.random() < P_B
    e = random.random() < P_E
    a = random.random() < P_A[(b, e)]
    w = pr(P_J[a], j) * pr(P_M[a], m)   # weight by how well evidence fits
    return b, w

samples = [weighted_sample(True, True) for _ in range(200_000)]
est = sum(w for b, w in samples if b) / sum(w for _, w in samples)

3. Reasoning Over Time: Hidden Markov Models

An HMM tracks a hidden state that changes over time and is observed only through noisy evidence: a robot's location from sensor readings, a speaker's words from audio, a patient's condition from test results. It's defined by a transition model P(Xt | Xt−1) and a sensor model P(Et | Xt).

hmm_filter.py
import numpy as np

# Hidden: weather (0 = rainy, 1 = sunny). Evidence: did the person carry an umbrella?
T = np.array([[0.7, 0.3],      # P(next | rainy)
              [0.3, 0.7]])     # P(next | sunny)
P_umbrella = np.array([0.9, 0.2])   # P(umbrella | rainy), P(umbrella | sunny)

def forward(observations, prior=np.array([0.5, 0.5])):
    belief = prior
    for saw_umbrella in observations:
        belief = T.T @ belief                                   # predict
        likelihood = P_umbrella if saw_umbrella else 1 - P_umbrella
        belief = likelihood * belief                            # update
        belief = belief / belief.sum()                          # normalize
        print(f"P(rain) = {belief[0]:.3f}")
    return belief

forward([True, True, False, True])

This predict–update loop is filtering. The Viterbi algorithm finds the most likely sequence of hidden states, and the same predict–update structure underlies the Kalman filters used in GPS navigation and self-driving cars.

4. Making Decisions: Expected Utility

Knowing probabilities isn't enough; an agent must act. A rational agent chooses the action with the highest expected utility: the probability-weighted average of the utility of each outcome.

expected_utility.py
p_rain = 0.35
utility = {
    ("umbrella", "rain"): 70,  ("umbrella", "dry"): 80,
    ("none", "rain"): 0,       ("none", "dry"): 100,
}

def eu(action):
    return p_rain * utility[(action, "rain")] + (1 - p_rain) * utility[(action, "dry")]

for a in ["umbrella", "none"]:
    print(a, eu(a))      # umbrella: 77.0, none: 65.0  -> take it

The value of information asks how much better the decision would be if you knew more — for example, whether checking a weather forecast is worth its cost. It's how diagnostic systems decide which test to order next.

From one decision to many

When decisions are sequential and each action changes the next state, expected utility becomes a Markov decision process — the foundation of reinforcement learning next week.

6. Knowledge Check

4 quick questions. Expand each to check your answer.

Q1

Why does a Bayesian network need far fewer numbers than a full joint distribution?

It exploits conditional independence: each variable depends only on its parents. Instead of one probability for every combination of all variables, you store one small table per node, which grows with the number of parents rather than the total number of variables.

Q2

Both neighbors called, yet P(burglary) is only about 0.28. Why so low?

Burglaries have a tiny prior probability (0.001) and false alarms are relatively common compared with that. Even strong evidence leaves the posterior moderate when the base rate is so low.

Q3

What are the two steps of HMM filtering?

Predict: push the current belief through the transition model to get the belief about the next state. Update: multiply by the likelihood of the new observation and normalize.

Q4

What does the value of information measure?

How much the expected utility of the best decision would increase if a piece of uncertain information became known. If it exceeds the cost of getting that information, gathering it is worthwhile.
