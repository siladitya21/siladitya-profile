Distributed Systems Course

Understand the systems behind every system

Databases, message queues, caches and cloud platforms are all distributed systems — and they all wrestle with the same handful of problems: machines fail independently, networks lose and delay messages, and there is no shared clock. This 16-week course builds the theory from first principles and turns it into working code, ending with a fault-tolerant key-value store running on your own Raft implementation. All 16 weeks are live, start to finish.

Before You Start

Prerequisites & tooling

What you should already know

  • Comfortable programming in at least one language — lesson examples are in Python for readability
  • Basic networking: what a request, a response and a TCP connection are
  • Have used a database and a web API; no prior distributed-systems theory needed
  • Pairs well with System Design: that course shows how to assemble these building blocks, this one shows how they work inside

Stack you'll work with

Every exercise runs on one laptop: simulated networks and multiple processes stand in for a real cluster. The capstone can be built in any language — Go is a great fit if you've taken the Go course.
